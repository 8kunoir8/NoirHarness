# M1.4 — Skills Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The harness owns a skill set: discover `SKILL.md` skills from a global directory and each workspace, resolve name collisions by precedence, enable/disable them, show them in a Skills view, and attribute skill loads in the event stream.

**Architecture:** The kernel scans two roots — `<dataDir>/skills` (global) and `<workspace>/.noir/skills` (project) — hashes every skill directory, resolves name collisions project-first, and materializes the enabled effective set into `<workspace>/.noir/skills-engine` with a manifest beside it. The managed `config.yml` lists that one directory through `skills.customDirectories` as a cwd-relative path, so each workspace's engine sees its own set. `EngineManager` reads the manifest at spawn and turns a tool call whose `rawInput.path` is `skill://<name>` into a `skill.loaded` event carrying the scope and hash the engine was given.

**Tech Stack:** TypeScript 5 strict, zod, better-sqlite3, React 19, `yaml`, Vitest, Playwright (Electron), omp 18.18.3 (ACP).

**Spec:** `docs/superpowers/specs/2026-11-09-noirharness-design.md` §7.2 (managed engine directory, skills), §8.1 (Skills rail item, list pane and `SKILL.md` viewer), §10 (Skills), §13 (M1.4 row).

## Evidence this plan rests on

Verified on this machine with omp 18.18.3, no model calls:

- `PI_CODING_AGENT_DIR=<dir> omp skill list --json` discovers `<dir>/skills/<name>/SKILL.md` with `"source": "native:user"`.
- The same command discovers `<cwd>/.agent/skills/<name>/SKILL.md` with `"source": "agents:project"`, but **not** `<cwd>/.noir/skills`.
- `config.yml` supports `skills.customDirectories: [ … ]`; relative entries resolve against the process cwd and report `"source": "custom:user"`. Duplicate names across the listed directories collapse to the **first** listed directory.
- A skill is loaded by the agent as a `read` tool call whose `rawInput.path` is `skill://<name>` (observed in an omp session log: `{"toolName":"read","args":{"path":"skill://brainstorming"}}`), which the ACP adapter already forwards as `rawInput`.

Consequence: the kernel does not need omp's own project discovery; it materializes the winners and points `config.yml` at them, which is what makes enable/disable and precedence authoritative.

## Global Constraints

- Node 24+, pnpm 10+, Windows-first. Never `python`/`sed` for edits; use the editor tools.
- TS strict with `noUncheckedIndexedAccess` and `exactOptionalPropertyTypes`; no `any`.
- The kernel is the only filesystem authority; every RPC validates its zod schema before touching a service.
- Workspace is the write boundary: no skill path (source or materialized) may resolve outside its root, and symlinks are never followed.
- The global skills root is `<dataDir>/skills` (spec: `%APPDATA%/NoirHarness/skills`); the project root is `<workspace>/.noir/skills`; both are kernel-created on demand.
- Materialized skill directories are kernel-owned and replaced wholesale; never write into a user's skill source directory.
- `config.yml` is generated: manual edits are overwritten. Skill materialization must not disturb `modelRoles`/`defaultThinkingLevel`.
- Events stay append-only with a gap-free per-session `seq`; the reducer stays replay-safe.
- Monaco stays bundled; no CDN. Playwright `getByLabel` is case-insensitive — pass `{ exact: true }`. Desktop Vitest has no jest-dom — assert `.textContent`/`.toBeTruthy()`.
- Existing e2e contract names keep working: nav `Main` buttons `Chats`/`Setup`, regions `Providers`/`Models`/`Projects`/`Sessions`/`Chat`, labels `Project path`, `Prompt`, `Send`, `Interrupt`, testids `kernel-status`, `session-status`, `message-assistant`, `tool-card`, `permission-card`.

## Review Focus

1. **A skill that is malformed or hostile.** A `SKILL.md` with no frontmatter, a missing `name`/`description`, a 5 MB body, a name containing `../`, a skill directory that is a symlink pointing outside the workspace, or a file inside a skill that is a symlink: none may crash the scan, escape a root, or enter the materialized set — the row is reported as a warning and the other skills still list.
2. **Name collision across scopes.** Same `name` under global and project: the project one is the only enabled/attributed skill, the global copy is reported as shadowed, and disabling the project copy does not silently resurrect the global copy.
3. **Disable/enable semantics.** Disabling a project skill removes it from the materialized directory and from the manifest; a session started afterwards does not see it; the source `SKILL.md` is untouched.
4. **Attribution honesty.** A `skill://` read for a name that is not in the materialized manifest emits nothing; a load emits exactly one `skill.loaded` per name per turn with the hash that was materialized, and the event survives replay.
5. **Missing or read-only `.noir`.** A workspace where `.noir` cannot be created (permissions, read-only drive) still starts sessions; skills are reported as unavailable rather than failing the turn.

```ts
import { createHash, randomUUID } from "node:crypto";
import { lstat, readdir, readFile } from "node:fs/promises";
import { join, sep } from "node:path";
import { parse as parseYaml } from "yaml";

export type SkillScope = "global" | "project";

export interface DiscoveredSkill {
  scope: SkillScope;
  name: string;
  description: string;
  /** Absolute path to the skill directory. */
  dir: string;
  hash: string;
}

export interface SkillScan {
  skills: DiscoveredSkill[];
  /** Global names hidden by a project skill of the same name. */
  shadowed: string[];
  /** `"<scope>:<dir>: <reason>"` for every directory that could not be used. */
  warnings: string[];
}

const MAX_SKILL_FILE_BYTES = 1024 * 1024;
const MAX_SKILL_FILES = 200;
const MAX_SKILL_BYTES = 8 * 1024 * 1024;
const SKILL_NAME = /^[A-Za-z0-9][A-Za-z0-9._-]{0,63}$/;

export function parseSkillFrontmatter(text: string): { name?: string; description?: string } {
  if (!text.startsWith("---")) return {};
  const end = text.indexOf("\n---", 3);
  if (end === -1) return {};
  const yaml = text.slice(3, end).replace(/^\r?\n/, "");
  let doc: unknown;
  try {
    doc = parseYaml(yaml);
  } catch {
    return {};
  }
  if (typeof doc !== "object" || doc === null || Array.isArray(doc)) return {};
  const record = doc as Record<string, unknown>;
  const name = typeof record.name === "string" ? record.name.trim() : undefined;
  const description = typeof record.description === "string" ? record.description.trim() : undefined;
  return {
    ...(name === undefined || name === "" ? {} : { name }),
    ...(description === undefined || description === "" ? {} : { description }),
  };
}

async function listFiles(dir: string, prefix: string, files: string[]): Promise<void> {
  if (files.length > MAX_SKILL_FILES) throw new Error(`more than ${MAX_SKILL_FILES} files`);
  const entries = await readdir(dir, { withFileTypes: true });
  entries.sort((a, b) => a.name.localeCompare(b.name));
  for (const entry of entries) {
    const absolute = join(dir, entry.name);
    const rel = prefix === "" ? entry.name : `${prefix}/${entry.name}`;
    // A symlink inside a skill could point outside the workspace; skip it rather than follow.
    if (entry.isSymbolicLink()) continue;
    if (entry.isDirectory()) await listFiles(absolute, rel, files);
    else if (entry.isFile()) files.push(rel);
  }
}

/** SHA-256 over every file's path, size and bytes in sorted order; symlinks are skipped. */
export async function hashSkillDir(dir: string): Promise<string> {
  const files: string[] = [];
  await listFiles(dir, "", files);
  const hash = createHash("sha256");
  let total = 0;
  for (const rel of files) {
    const bytes = await readFile(join(dir, ...rel.split("/")));
    total += bytes.length;
    if (total > MAX_SKILL_BYTES) throw new Error(`more than ${MAX_SKILL_BYTES} bytes`);
    hash.update(rel.replaceAll(sep, "/"));
    hash.update("\0");
    hash.update(String(bytes.length));
    hash.update("\0");
    hash.update(bytes);
  }
  return hash.digest("hex");
}

async function readSkill(scope: SkillScope, dir: string): Promise<{ name: string; description: string; hash: string }> {
  const info = await lstat(dir);
  if (!info.isDirectory()) throw new Error("not a directory");
  const body = await readFile(join(dir, "SKILL.md"));
  if (body.length > MAX_SKILL_FILE_BYTES) throw new Error("SKILL.md is larger than 1 MiB");
  const front = parseSkillFrontmatter(body.toString("utf8"));
  if (front.name === undefined) throw new Error("SKILL.md has no name");
  if (!SKILL_NAME.test(front.name)) throw new Error(`"${front.name}" is not a valid skill name`);
  if (front.description === undefined) throw new Error("SKILL.md has no description");
  return { name: front.name, description: front.description, hash: await hashSkillDir(dir) };
}

async function scanRoot(
  scope: SkillScope,
  rootDir: string | undefined,
  skills: Map<string, DiscoveredSkill>,
  warnings: string[],
): Promise<void> {
  if (rootDir === undefined) return;
  const entries = await readdir(rootDir, { withFileTypes: true }).catch((error: NodeJS.ErrnoException) => {
    if (error.code === "ENOENT") return [];
    throw error;
  });
  for (const entry of entries) {
    if (!entry.isDirectory() || entry.isSymbolicLink()) continue;
    const dir = join(rootDir, entry.name);
    try {
      const read = await readSkill(scope, dir);
      if (!skills.has(read.name)) skills.set(read.name, { scope, dir, ...read });
    } catch (error) {
      warnings.push(`${scope}:${entry.name}: ${error instanceof Error ? error.message : String(error)}`);
    }
  }
}

/**
 * Project skills are scanned first: a name present in both scopes resolves to the project copy,
 * and the global copy is reported as shadowed instead of silently winning somewhere else.
 */
export async function discoverSkills(globalDir: string, projectDir: string | undefined): Promise<SkillScan> {
  const skills = new Map<string, DiscoveredSkill>();
  const warnings: string[] = [];
  const shadowed: string[] = [];
  await scanRoot("project", projectDir, skills, warnings);
  const projectNames = new Set(skills.keys());
  const global = new Map<string, DiscoveredSkill>();
  const globalWarnings: string[] = [];
  await scanRoot("global", globalDir, global, globalWarnings);
  warnings.push(...globalWarnings);
  for (const [name, skill] of global) {
    if (projectNames.has(name)) {
      shadowed.push(name);
      continue;
    }
    skills.set(name, skill);
  }
  return {
    skills: [...skills.values()].sort((a, b) => a.name.localeCompare(b.name)),
    shadowed: shadowed.sort(),
    warnings: warnings.sort(),
  };
}

import { cp, mkdir, rename, rm, writeFile } from "node:fs/promises";
import type Database from "better-sqlite3";
import { ErrorCodes, RpcFault } from "@noir/protocol";
import { v7 as uuidv7 } from "uuid";

export interface SkillManifest {
  version: 1;
  skills: { name: string; scope: SkillScope; hash: string; description: string }[];
}

export interface SkillRowView {
  scope: SkillScope;
  name: string;
  description: string;
  hash: string;
  enabled: boolean;
}

async function writeJsonAtomically(target: string, value: unknown): Promise<void> {
  const tmp = `${target}.${randomUUID()}.tmp`;
  await writeFile(tmp, JSON.stringify(value, null, 2), "utf8");
  await rename(tmp, target);
}

/** Copies a skill directory without following symlinks; the destination replaces any old copy. */
async function copySkill(src: string, dest: string): Promise<void> {
  await mkdir(dest, { recursive: true });
  for (const entry of await readdir(src, { withFileTypes: true })) {
    if (entry.isSymbolicLink()) continue;
    const from = join(src, entry.name);
    const to = join(dest, entry.name);
    if (entry.isDirectory()) await copySkill(from, to);
    else if (entry.isFile()) await cp(from, to);
  }
}

async function replaceDir(staging: string, target: string): Promise<void> {
  await rm(target, { recursive: true, force: true });
  await rename(staging, target);
}

export class SkillService {
  constructor(private readonly db: Database.Database, private readonly dataDir: string) {}

  private get globalRoot(): string {
    return join(this.dataDir, "skills");
  }
  private readEnabled(workspaceId: string): Map<string, boolean> {
    const rows = this.db
      .prepare("SELECT workspace_id, scope, name, enabled FROM skills")
      .all() as Array<{ workspace_id: string; scope: SkillScope; name: string; enabled: number }>;
    const flags = new Map<string, boolean>();
    for (const row of rows) {
      if (row.workspace_id !== "" && row.workspace_id !== workspaceId) continue;
      flags.set(`${row.workspace_id}|${row.scope}|${row.name}`, row.enabled === 1);
    }
    return flags;
  }

  private enabledFor(workspaceId: string, flags: Map<string, boolean>, skill: DiscoveredSkill): boolean {
    const key = `${skill.scope === "global" ? "" : workspaceId}|${skill.scope}|${skill.name}`;
    return flags.get(key) ?? true;
  }

  private persist(workspaceId: string, skill: DiscoveredSkill): void {
    this.db
      .prepare(
        "INSERT INTO skills (id, workspace_id, scope, name, dir, hash, manifest_json, enabled) VALUES (?,?,?,?,?,?,?,1) " +
          "ON CONFLICT (workspace_id, scope, name) DO UPDATE SET dir = excluded.dir, hash = excluded.hash, manifest_json = excluded.manifest_json",
      )
      .run(
        uuidv7(),
        skill.scope === "global" ? "" : workspaceId,
        skill.scope,
        skill.name,
        skill.dir,
        skill.hash,
        JSON.stringify({ name: skill.name, description: skill.description }),
      );
  }

  /** Scans both roots, refreshes hashes in the DB, and returns every usable row with its flag. */
  async list(
    workspaceId: string,
    root: string | undefined,
  ): Promise<{ skills: SkillRowView[]; shadowed: string[]; warnings: string[] }> {
    const projectDir = root === undefined ? undefined : join(root, ".noir", "skills");
    const scan = await discoverSkills(this.globalRoot, projectDir);
    for (const skill of scan.skills) this.persist(workspaceId, skill);
    const flags = this.readEnabled(workspaceId);
    return {
      skills: scan.skills.map((skill) => ({
        scope: skill.scope,
        name: skill.name,
        description: skill.description,
        hash: skill.hash,
        enabled: this.enabledFor(workspaceId, flags, skill),
      })),
      shadowed: scan.shadowed,
      warnings: scan.warnings,
    };
  }

  async setEnabled(
    workspaceId: string,
    root: string | undefined,
    scope: SkillScope,
    name: string,
    enabled: boolean,
  ): Promise<void> {
    const listed = await this.list(workspaceId, root);
    const skill = listed.skills.find((row) => row.scope === scope && row.name === name);
    if (skill === undefined) throw new RpcFault(ErrorCodes.notFound, `Skill not found: ${name}`);
    this.db
      .prepare(
        "INSERT INTO skills (id, workspace_id, scope, name, dir, hash, manifest_json, enabled) VALUES (?,?,?,?,?,?,?,?) " +
          "ON CONFLICT (workspace_id, scope, name) DO UPDATE SET enabled = excluded.enabled",
      )
      .run(uuidv7(), scope === "global" ? "" : workspaceId, scope, name, "", skill.hash, "{}", enabled ? 1 : 0);
    if (root !== undefined) await this.materialize(workspaceId, root);
  }

  async read(
    workspaceId: string,
    root: string | undefined,
    scope: SkillScope,
    name: string,
  ): Promise<{ content: string; hash: string; truncated: false }> {
    const listed = await this.list(workspaceId, root);
    const skill = listed.skills.find((row) => row.scope === scope && row.name === name);
    if (skill === undefined) throw new RpcFault(ErrorCodes.notFound, `Skill not found: ${name}`);
    const projectDir = root === undefined ? undefined : join(root, ".noir", "skills");
    const scan = await discoverSkills(this.globalRoot, projectDir);
    const found = scan.skills.find((row) => row.scope === scope && row.name === name);
    if (found === undefined) throw new RpcFault(ErrorCodes.notFound, `Skill not found: ${name}`);
    const content = await readFile(join(found.dir, "SKILL.md"), "utf8");
    return { content, hash: found.hash, truncated: false };
  }

  /**
   * Writes the effective set for one workspace into `<workspace>/.noir/skills-engine` plus its
   * manifest. One directory per workspace makes precedence intrinsic: `discoverSkills` never
   * yields a global copy whose name a project skill claims, even when that project skill is
   * disabled, so disabling it cannot resurrect the global one. The directory is staged and
   * renamed in; a read-only workspace simply ends up with no materialized skills.
   */
  async materialize(workspaceId: string, root: string): Promise<void> {
    const noir = join(root, ".noir");
    const scan = await discoverSkills(this.globalRoot, join(noir, "skills"));
    const flags = this.readEnabled(workspaceId);
    const target = join(noir, "skills-engine");
    const staging = `${target}.tmp-${randomUUID()}`;
    const manifest: SkillManifest = { version: 1, skills: [] };
    try {
      await mkdir(noir, { recursive: true });
      await rm(staging, { recursive: true, force: true });
      await mkdir(staging, { recursive: true });
      for (const skill of scan.skills) {
        if (!this.enabledFor(workspaceId, flags, skill)) continue;
        await copySkill(skill.dir, join(staging, skill.name));
        manifest.skills.push({ name: skill.name, scope: skill.scope, hash: skill.hash, description: skill.description });
      }
      await replaceDir(staging, target);
      await writeJsonAtomically(join(noir, "skills-engine.json"), manifest);
    } catch {
      await rm(staging, { recursive: true, force: true }).catch(() => undefined);
    }
  }

  /** Scope and hash as materialized for this workspace; absent when nothing was written. */
  async manifestFor(root: string | undefined): Promise<Map<string, { scope: SkillScope; hash: string }>> {
    const merged = new Map<string, { scope: SkillScope; hash: string }>();
    if (root === undefined) return merged;
    try {
      const manifest = JSON.parse(await readFile(join(root, ".noir", "skills-engine.json"), "utf8")) as SkillManifest;
      for (const skill of manifest.skills) merged.set(skill.name, { scope: skill.scope, hash: skill.hash });
    } catch {
      // No manifest means nothing was materialized for this workspace, so nothing is attributed.
    }
    return merged;
  }
}
```

`materialize` takes the workspace id because the enable flags it reads are keyed by workspace. `setEnabled` and `EngineManager` pass the same id. There is no shared global materialized directory, so two workspaces can never race over one; each workspace's staging path is unique.

```md
## Skills

Each workspace gets a skill set from two directories: `%APPDATA%/NoirHarness/skills` (global) and
`<workspace>/.noir/skills` (project). A skill is a directory with a `SKILL.md` whose frontmatter
carries `name` and `description`. When both scopes define a name, the project copy wins and the
global one is marked shadowed.

The kernel hashes each skill directory, copies the enabled effective set into
`<workspace>/.noir/skills-engine`, and points the generated `config.yml` at it with a cwd-relative
`skills.customDirectories` entry. Global skills are copied into each workspace that uses them, so a
name claimed by a project skill stays claimed even when that project skill is disabled. Disabling a
skill removes it from the materialized copy — never from its source — and applies to the next
session started in that workspace. A `skill://` read by the engine becomes a `skill.loaded` event
carrying the name, scope and hash; the chat shows a `Skills loaded` group.

The `Skills` view lists both scopes with a hash, a live toggle, and a read-only `SKILL.md` viewer.
A directory without valid frontmatter, a symlink, or a `SKILL.md` over 1 MiB is reported as a
warning and skipped rather than failing the scan.
```

## Risks and open items

- **omp behavior beyond the probe:** the plan relies on `skills.customDirectories` with a relative entry (verified on 18.18.3) and on the agent loading skills as `read` with `skill://<name>` (observed in a real session log). A future omp release could change either; the fallback is to also copy the global winners into `<agentDir>/skills`, which loses the shadowing guarantee for global names but keeps discovery working.
- **Attribution is heuristic at the edge:** an engine that inlines a skill body without a `skill://` read produces no `skill.loaded`. The event is honest about what was observed, not about what the model used.
- **Disable applies per spawn:** a running session keeps the old materialized copy until its engine is recreated. Documented; not a defect.
- **Global skill toggles are machine-wide:** stored with `workspace_id = ''`, so disabling a global skill affects every workspace. That matches "global". The copy still lands per workspace, so an engine spawn picks the change up on its next start.
- **A read-only workspace has no skills:** materialization is skipped when `.noir` cannot be created, so the engine starts with none while the Skills view still lists the sources. That is the deliberate degradation; surfacing the condition in the view is out of scope.
