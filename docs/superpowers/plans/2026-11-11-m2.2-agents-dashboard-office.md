# M2.2 Agents Dashboard and Pixel Office Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship persistent agent profiles, a live roster, permission-policy enforcement, and a Phaser pixel office that visualizes real kernel events.

**Architecture:** Extend the existing `agents` table and `SessionService`; add an `AgentService` for CRUD/roster and a policy check inside `EngineManager.handlePermission`. The renderer gains an Agents view whose main pane is a lazily loaded Phaser scene fed by `agent.roster` and broadcast events.

**Tech Stack:** better-sqlite3, zod RPC, React 19, Phaser 3, Vite, Vitest, Playwright Electron.

**Spec:** `docs/superpowers/specs/2026-11-11-m2.2-agents-dashboard-office-design.md`

## Global Constraints

- TypeScript strict + `noUncheckedIndexedAccess` + `exactOptionalPropertyTypes`; ESM `.js` extensions.
- Kernel is the only DB/fs authority; every RPC parses zod first.
- `agents.skill_ids` is reserved; do not add per-agent skill filtering or a selection UI.
- Policy is read from the session snapshot, never the live profile.
- Office renders from `agent.roster` + broadcast events only; no kernel access in Phaser.
- CC0 assets only; no upstream art or runtime.
- Windows-first; Phaser must fall back to Canvas and keep the roster usable.

## Review Focus

- Editing an agent profile while its session runs must not change that session's model or policy.
- `allow` on `shell` must not create an approval row, and replay must still show the decision.
- A session with no agent (legacy path) must still be creatable and visible.
- The office must not leak a `Phaser.Game` when the view or workspace changes, and must stay usable with reduced motion.
- Desk assignment must be stable across restarts and collision-free for many agents.

  delete: z.enum(["ask", "allow", "reject"]),
  rename: z.enum(["ask", "allow", "reject"]),
  "write-outside-workspace": z.enum(["ask", "allow", "reject"]),
  network: z.enum(["ask", "allow", "reject"]),

export type PermissionCategory = z.infer<typeof PermissionCategory>;
export type PermissionPolicy = z.infer<typeof PermissionPolicySchema>;

export const AgentCreateParams = z.object({

  role: z.string().trim().min(1).max(40).default("Coder"),
  engineId: z.enum(["acp", "native"]).default("acp"),
  modelRef: z.string().min(1).nullable().default(null),
  permissionPolicy: PermissionPolicySchema.default({}),
  defaultWorkspaceId: z.string().min(1).nullable().default(null),
});
export const AgentUpdateParams = AgentCreateParams.partial().extend({ id: z.string().min(1) });
export const AgentArchiveParams = z.object({ id: z.string().min(1), archived: z.boolean() });
export const AgentListParams = z.object({ includeArchived: z.boolean().optional() });
export const AgentListResult = z.object({ agents: z.array(AgentView) });
export const AgentArchiveResult = z.object({ ok: z.literal(true) });

`AgentView` is added to `rpc.ts` too, matching spec §5 exactly. Use `.strict()` on `PermissionPolicySchema` so a typo'd category is rejected instead of silently ignored.

Migration 6 exactly as spec §4. `AgentService` (constructor `(db, models)`) uses SQL with `archived_at IS NULL` unless `includeArchived`; the duplicate check is `SELECT id FROM agents WHERE lower(name) = lower(?) AND archived_at IS NULL`; `create` writes `created_at = Date.now()` and `permission_policy = JSON.stringify(policy)`; `update` merges only the provided fields into one `UPDATE`; `archive` sets or clears `archived_at` (idempotent, no error when already in that state); `list` orders by `lower(name)`.

Validation in `create`/`update`:

- `modelRef` must resolve through `models.enabledModel(id)` → else `RpcFault(notFound, "Model not found")`; a disabled model is the same fault as `SessionService.requireEnabledModel` gives.

- `defaultWorkspaceId` must exist in `workspaces` → else `notFound("Workspace not found")`.

Handlers in `packages/kernel/src/index.ts` parse with `Agent*Params` and return the service result. `AgentService` is constructed next to `SessionService` and passed to `EngineManager` (used by Task 3's policy read).

`isInsideWorkspace(root, rawInput)`:

```ts
function isInsideWorkspace(root: string, rawInput: unknown): boolean {
  const input = rawInput as { path?: unknown } | null | undefined;
  if (typeof input?.path !== "string" || input.path === "") return false; // fail closed
  try {
    const rel = resolve(root, input.path);
    const inside = relative(root, rel);
    return inside !== "" && !inside.startsWith("..") && !isAbsolute(inside);
  } catch {
    return false;
  }
}
```

```ts
roster(): AgentRosterEntry[] {
  const sessions = this.sessions.list();
  return this.list().map((agent) => {
    const mine = sessions.filter((s) => s.agentId === agent.id);
    const open = mine.filter((s) => s.status !== "closed");
    const active = open[0]; // list() is created_at DESC
    const status = mine.some((s) => s.pendingApproval) ? "needs_you"
      : mine.some((s) => s.status === "running" || s.status === "starting") ? "working"
      : mine.some((s) => s.status === "error") ? "error" : "idle";
    return { agentId: agent.id, name: agent.name, role: agent.role, status,
      activeSessionId: active?.id ?? null, activeSessionStatus: active?.status ?? null,
      activeToolKind: active === undefined ? null : this.toolKindOf(active.id),
      sessionCount: mine.length, lastActivityAt: mine[0]?.lastEventAt ?? agent.createdAt,
      usage: active === undefined ? null : this.usageOf(active.id) };
  });
}
```

`toolKindOf` runs `SELECT payload_json FROM events WHERE session_id = ? AND type = 'tool.started' ORDER BY seq DESC, rowid DESC LIMIT 1` and returns the parsed `kind` when it is one of the six enum values, else `null`. `usageOf` does the same for `usage.updated` and maps to `{ used: contextUsed, size: contextWindow }`. Both parse inside `try`/`catch` and return `null` on malformed JSON.

Sort the result by status urgency (`needs_you`, `working`, `error`, `idle`), then `name`, so the office paints the important characters first.

const host = useRef<HTMLDivElement>(null);
useEffect(() => {
  let game: Phaser.Game | undefined;

  // Phaser and the scene load together, so the initial renderer bundle never includes either.
  void Promise.all([import("phaser"), import("./scene.js")]).then(([{ default: Phaser }, { createOfficeScene }]) => {
    if (cancelled || !host.current) return;

      game = new Phaser.Game({ type: Phaser.AUTO, parent: host.current, width: 768, height: 512,

  });
  return () => { cancelled = true; game?.destroy(true); };
