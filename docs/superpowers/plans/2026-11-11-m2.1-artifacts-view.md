# M2.1 Artifacts View Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Open Markdown, CSV/TSV, and PDF workspace files in a read-only main-pane preview tab, served through the kernel.

**Architecture:** `artifact.read` is a new kernel RPC that resolves a path inside a workspace and returns UTF-8 or base64 with caps. The renderer owns three preview renderers behind one `ArtifactPreview` component; the tab system gains a workspace-scoped `preview` kind.

**Tech Stack:** zod, better-sqlite3 workspace lookup, React 19, react-markdown/remark-gfm/rehype-sanitize, pdfjs-dist, Playwright Electron, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-11-m2.1-artifacts-view-design.md`

## Global Constraints

- TypeScript strict + `noUncheckedIndexedAccess` + `exactOptionalPropertyTypes`; ESM `.js` extensions.
- Kernel is the only fs authority. The renderer never reads files directly.
- Every RPC validates its zod schema before touching the filesystem.
- No raw HTML rendering; no remote resources; no `dangerouslySetInnerHTML`.
- Windows-first; paths may contain spaces and non-ASCII characters.
- Tests: no screenshot snapshots, no tests for wiring-only code.

## Review Focus

- A Markdown file containing `<script>`, `<img onerror=…>`, and `javascript:` links must render inert.
- A CSV with quoted commas, embedded newlines, and a UTF-8 BOM must parse into the intended table.
- A PDF just under the cap must render; just over it must produce a refusal state, not a crash.
- A preview tab restored after restart must re-read the file and show a deleted-file state if it is gone.
- A path containing `..` or a symlink escaping the workspace must be rejected.

`readArtifact` lives in `packages/kernel/src/fsService.ts` itself, so it reuses the module-private `decodeText`/`readHead` and the exported `relativePath`/`resolveInsideRoot` with no new exports and no second path guard. Only `readArtifact`, the two caps, and the `ArtifactReadResult` wiring are new exports.

```ts
export const MAX_ARTIFACT_TEXT_BYTES = 2 * 1024 * 1024;
export const MAX_ARTIFACT_PDF_BYTES = 32 * 1024 * 1024;

export async function readArtifact(root: string, value: string): Promise<ArtifactReadResult> {
  const rel = relativePath(value);
  const ext = extname(rel).toLowerCase();
  const binary = ext === ".pdf";
  if (!binary && ![".md", ".markdown", ".csv", ".tsv"].includes(ext)) {
    throw new RpcFault(ErrorCodes.invalidParams, `Unsupported artifact type: ${rel}`);
  }
  const absolute = resolveInsideRoot(root, rel);
  const info = await stat(absolute).catch(() => {
    throw new RpcFault(ErrorCodes.notFound, `File not found: ${rel}`);
  });
  if (!info.isFile()) throw new RpcFault(ErrorCodes.invalidParams, `Not a file: ${rel}`);
  if (binary && info.size > MAX_ARTIFACT_PDF_BYTES) {
    throw new RpcFault(ErrorCodes.conflict, "Artifact is larger than 32 MB");
  }
  const cap = binary ? MAX_ARTIFACT_PDF_BYTES : MAX_ARTIFACT_TEXT_BYTES;
  const truncated = info.size > cap;
  const bytes = await readHead(absolute, Math.min(info.size, cap));
  return {
    encoding: binary ? "base64" : "utf8",
    content: binary ? bytes.toString("base64") : decodeText(bytes, truncated, rel),
    size: info.size,
    mtimeMs: Math.floor(info.mtimeMs),
    truncated,
  };
}
```

`decodeText` throws `Not a UTF-8 text file: <path>` for invalid UTF-8, which is the correct refusal for a mislabeled `.md`; reject a NUL byte the same way `readFileText` does (`bytes.includes(0)`), so a binary file renamed to `.csv` never reaches the parser as mojibake. `import { extname } from "node:path"` is added with the function.

Protocol (`packages/protocol/src/rpc.ts`), next to the other `fs.*` entries:

```ts
export const ArtifactReadParams = z.object({ workspaceId: z.string().min(1), path: z.string().min(1) });
export const ArtifactReadResult = z.object({
  encoding: z.enum(["utf8", "base64"]),
  content: z.string(),
  size: z.number().int().nonnegative(),
  mtimeMs: z.number().int(),
  truncated: z.boolean(),
});
export type ArtifactReadParams = z.infer<typeof ArtifactReadParams>;
export type ArtifactReadResult = z.infer<typeof ArtifactReadResult>;
```

`Methods.artifactRead = "artifact.read"` goes into the `Methods` object. The handler sits next to `fs.read`:

```ts
[Methods.artifactRead]: async (params) => {
  const parsed = ArtifactReadParams.parse(params);
  return readArtifact(workspaceRoot(parsed.workspaceId), parsed.path);
},
```

```ts
const KINDS: Record<string, PreviewKind> = {
```

`ArtifactPreview` renders a header with the path and a Reload button, then one of four states:

```tsx
type PreviewState =
  | { status: "loading" }
  | { status: "ready"; result: ArtifactReadResult }
  | { status: "error"; message: string };

const [state, setState] = useState<PreviewState>({ status: "loading" });
const [reloadKey, setReloadKey] = useState(0);
useEffect(() => {
  let live = true;
  setState({ status: "loading" });
  request<ArtifactReadResult>("artifact.read", { workspaceId, path })
    .then((result) => { if (live) setState({ status: "ready", result }); })
    .catch((error: unknown) => {
      if (live) setState({ status: "error", message: error instanceof Error ? error.message : "Could not read the file" });

  return () => { live = false; };
}, [workspaceId, path, reloadKey]);
```

Add `pdfjs-dist`. Decode helper in `preview/bytes.ts` (unit-testable without pdf.js):

```ts
/** `atob` yields a binary string; the PDF parser needs bytes, so copy through char codes. */
export function base64ToBytes(base64: string): Uint8Array {
  const binary = atob(base64);
  const bytes = new Uint8Array(binary.length);
  for (let index = 0; index < binary.length; index += 1) bytes[index] = binary.charCodeAt(index);
  return bytes;
}
```

`PdfArtifact` loads pdf.js once. The worker is a Vite `?url` import (the same lazy pattern as the Monaco workers), so the asset gets a hashed name under `dist/renderer/assets` and is packed into `app.asar`; a bare-specifier `new URL("pdfjs-dist/…", import.meta.url)` does not resolve a package path at runtime:

```ts
let loading: Promise<typeof import("pdfjs-dist")> | undefined;
function loadPdfJs() {
  loading ??= (async () => {
    const [pdfjs, worker] = await Promise.all([
      import("pdfjs-dist"),
      import("pdfjs-dist/build/pdf.worker.min.mjs?url"),
    ]);
    pdfjs.GlobalWorkerOptions.workerSrc = worker.default;
    return pdfjs;
  })();
  return loading;
}
```

Both imports stay dynamic; a top-level `import "pdfjs-dist"` would add ~1 MB to the entry chunk.

Behaviour:

- `getDocument({ data })` once per `base64` prop; keep the `PDFDocumentProxy` in a ref and destroy it on unmount (`doc.destroy()`).
- Page count renders as soon as the document resolves (`1 / 3`), before the first paint.
- Render the current page into a `<canvas>` sized `viewport.width * devicePixelRatio`; set `style.width` to the CSS size so the bitmap stays crisp.
- Toolbar: prev/next (disabled at the ends), zoom out/in (0.5–3, step 0.25), fit width.
- Cancel an in-flight render before starting another: keep the `RenderTask` in a ref and `task.cancel()`; swallow the resulting `RenderingCancelledException`.
- `ResizeObserver` on the pane recomputes fit width, debounced 150 ms.
- Errors: `catch` around `getDocument` and `page.render`, message from `error.message` with a newline split so no stack leaks; render "Could not read PDF" plus the message.

- `<table>` with a sticky `<thead>`; window the body to `[scrollTop / rowHeight - 50, + 100]` rows, with a spacer row above and below to keep the scrollbar honest.
