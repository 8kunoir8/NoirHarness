# M6.0 Rewind Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give the transcript a rewind: restore the workspace and the conversation to the moment before any user prompt, in place, on any engine.

**Architecture:** A `CheckpointService` owns one hidden git repository per workspace (`<dataDir>/checkpoints/<workspaceId>/`, work tree = the workspace, never the user's `.git`). A tree is written at every turn start and pinned by `refs/noir/<sessionId>/<checkpointId>`. Restoring writes that tree back over the differing paths and appends a `session.rewound` event naming the cut range; nothing is deleted, and one `EventStore` helper hides abandoned ranges from the replay, the native engine's history, forks and session meta. The renderer rebuilds its transcript from a filtered replay and draws one marker line per rewind.

**Tech Stack:** Git CLI (already a soft dependency via `gitService.ts`), better-sqlite3 migration 11, zod schemas in `@noir/protocol`, React 19 renderer, Vitest, Playwright Electron.

**Spec:** `docs/superpowers/specs/2026-11-14-m6.0-checkpoint-rewind-design.md`

- Never log a file's contents, a token, a prompt, or a credential.
- One commit per task, on `main`. Commit with `git commit -F .superpowers/commit-msg.txt`; never amend, never branch, never push.
- `git config core.autocrlf=true` is set on this machine: committed blobs are LF. Python file edits must use `encoding='utf-8'` and `newline='\\n'`; do not use Python for source edits at all — use `sd`/`edit`.
- Any file added under `apps/desktop/src/renderer/office/assets/` needs a licence beside it. Nothing in this plan adds art.
- Kernel error codes: `notFound = -32004`, `conflict = -32009`, `internal = -32603`. There is no `busy` code; "busy" is `conflict` with the message `A turn is running in this workspace`.
- Unit gate: `pnpm -r typecheck` and `pnpm -r test` (~40 s). E2E gate: `cd apps/desktop && pnpm test:e2e` (~8.3 min, builds first). Run each gate once, at the task that needs it, not per step.
- Tests own their temporary directories and remove them in `afterEach`; no test may write to `%APPDATA%\\NoirHarness`.
- `NOIR_GIT_COMMAND` overrides the git binary (already honoured by `gitService.ts`); the checkpoint store honours it too, so tests can point it at a fake.

## Review Focus

1. **A workspace whose `.gitattributes` requests LFS** — a pointer file would be captured and written back over real content. Expected: no snapshots for that workspace, `available: false`, and the reason on screen. Pinned by Task 3.
2. **CRLF bytes on a machine with `autocrlf=true`** — restore must return the exact bytes captured, not a normalised copy. Pinned by Task 4.
3. **An ignored/excluded directory (`node_modules`)** — a restore that removes everything else must not delete into it. Pinned by Tasks 3 and 4.
4. **A rewind while another session in the same workspace is mid-turn** — the restore would race that turn's writes. Expected: refused with `conflict`, action disabled. Pinned by Tasks 6 and 9.
5. **A rewind, then a fork or a second rewind** — abandoned ranges must keep resolving (seq arithmetic, not one watermark). Pinned by Task 2 and Task 6.

```ts
  /**
   * The ranges a rewind abandoned, as `[from, to)`: `from` is the checkpoint's seq (the turn about
   * to start) and `to` is the rewind event's own seq, which stays visible.
   */
  rewoundRanges(sessionId: string): Array<{ from: number; to: number }> {
    const rows = this.db
      .prepare("SELECT seq, payload_json FROM events WHERE session_id = ? AND type = 'session.rewound' ORDER BY seq ASC")
      .all(sessionId) as Array<{ seq: number; payload_json: string }>;
    return rows.flatMap((row) => {
      const payload: unknown = JSON.parse(row.payload_json);
      const cut = typeof payload === "object" && payload !== null && "cutSeq" in payload ? payload.cutSeq : undefined;
      return typeof cut === "number" ? [{ from: cut, to: row.seq }] : [];
    });
  }

  /** Everything a reader may see: the log minus the abandoned ranges. */
  visible(sessionId: string, sinceSeq = 0): AgentEvent[] {
    const ranges = this.rewoundRanges(sessionId);
    return this.list(sessionId, sinceSeq).filter(
      (event) => !ranges.some((range) => event.seq >= range.from && event.seq < range.to),
    );
  }

  /** One event by seq, abandoned or not: the marker's `Load the prompt again` reads across the cut. */
  at(sessionId: string, seq: number): AgentEvent | undefined {
    return this.list(sessionId, seq - 1).find((event) => event.seq === seq);
  }

  /** The seq the next append will take, so a turn can name its cut before it writes anything. */
  nextSeq(sessionId: string): number {
    const row = this.db.prepare("SELECT COALESCE(MAX(seq), 0) + 1 AS next FROM events WHERE session_id = ?").get(sessionId) as { next: number };
    return row.next;
  }

  /** Newest visible event, without loading the log. Ranges are few, so the clauses are few. */
  visibleMeta(sessionId: string): { lastSeq: number; lastTs: number; pendingApproval: boolean } {
    const ranges = this.rewoundRanges(sessionId);
    const exclusion = ranges.map(() => "AND NOT (seq >= ? AND seq < ?)").join(" ");
    const args = ranges.flatMap((range) => [range.from, range.to]);
    const stat = this.db
      .prepare(`SELECT MAX(seq) AS last_seq, MAX(ts) AS last_ts FROM events WHERE session_id = ? ${exclusion}`)
      .get(sessionId, ...args) as { last_seq: number | null; last_ts: number | null };
    const pending = this.db
      .prepare(
        `SELECT type FROM events WHERE session_id = ? ${exclusion} AND type IN ('permission.requested', 'permission.resolved') ORDER BY seq DESC LIMIT 1`,
      )
      .get(sessionId, ...args) as { type: string } | undefined;
    return { lastSeq: stat.last_seq ?? 0, lastTs: stat.last_ts ?? 0, pendingApproval: pending?.type === "permission.requested" };
  }
```

Create `packages/kernel/src/checkpoints.ts`. The store layout, config keys and forced excludes come straight from spec §3 and are not negotiable:

```ts
import { execFile } from "node:child_process";
import { mkdir, readFile, stat, statfs, writeFile } from "node:fs/promises";
import { isAbsolute, join, relative, sep } from "node:path";
import { promisify } from "node:util";
import type Database from "better-sqlite3";
import { v7 as uuidv7 } from "uuid";
import { ErrorCodes, RpcFault, type CheckpointView } from "@noir/protocol";
import type { EventStore } from "./eventStore.js";

const run = promisify(execFile);
const GIT_TIMEOUT_MS = 120_000;
const MIN_FREE_BYTES = 500 * 1024 * 1024;
const MAX_NOT_CAPTURED = 5_000;
const IDENTITY = ["-c", "user.name=NoirHarness", "-c", "user.email=checkpoints@noir.local"];

/**
 * Directories no restore should ever move. `.gitignore` cannot be trusted for this: a project that
 * keeps `node_modules` tracked would put hundreds of megabytes in the store on its first turn.
 */
const FORCED_EXCLUDES = [
  ".git/", "node_modules/", "dist/", "build/", "out/", "release/", "target/",
  ".next/", ".cache/", "vendor/", "coverage/",
];

export interface CaptureInput {
  sessionId: string;
  workspaceId: string;
  workspaceRoot: string;
  turnId: string | null;
  seq: number;
  label?: "turn" | "pre-restore";
}

export interface CheckpointRow extends CheckpointView {
  workspaceId: string;
  workspaceRoot: string;
  treeSha: string | null;
  commitSha: string | null;
}

interface Row {
  id: string; workspace_id: string; session_id: string; turn_id: string | null; seq: number;
  tree_sha: string | null; commit_sha: string | null; label: string; created_at: number;
  not_captured: number; error: string | null; path: string;
}

export class CheckpointService {
  private readonly gitCommand: string;
  private healthCache: { checkpoints: "ok" | "unavailable"; checkpointReason?: string } | undefined;

  constructor(
    private readonly db: Database.Database,
    private readonly events: EventStore,
    private readonly opts: { dataDir: string; gitCommand?: string },
  ) {
    this.gitCommand = opts.gitCommand ?? process.env.NOIR_GIT_COMMAND ?? "git";
  }

  entries(sessionId: string): CheckpointView[] {
    const ranges = this.events.rewoundRanges(sessionId);
    return this.rows(sessionId)
      .filter((row) => !ranges.some((range) => row.seq >= range.from && row.seq < range.to))
      .map((row) => ({
        id: row.id,
        turnId: row.turn_id,
        seq: row.seq,
        createdAt: row.created_at,
        notCaptured: row.not_captured,
        label: row.label === "pre-restore" ? "pre-restore" : "turn",
        error: row.error,
      }));
  }

  async availability(workspaceId: string): Promise<{ available: boolean; reason?: string }> {
    const health = await this.health();
    if (health.checkpoints === "unavailable") {
      return { available: false, reason: health.checkpointReason ?? "not available" };
    }
    const row = this.db.prepare("SELECT path FROM workspaces WHERE id = ?").get(workspaceId) as { path: string } | undefined;
    if (row === undefined) return { available: false, reason: "workspace missing" };
    try {
      await stat(row.path);
    } catch {
      return { available: false, reason: "workspace missing" };
    }
    const refusal = await this.refusal(row.path);
    return refusal === undefined ? { available: true } : { available: false, reason: refusal };
  }

  /** Cached: `system.health` is polled, and a missing binary does not appear mid-run. */
  async health(): Promise<{ checkpoints: "ok" | "unavailable"; checkpointReason?: string }> {
    if (this.healthCache !== undefined) return this.healthCache;
    try {
      await run(this.gitCommand, ["--version"], { timeout: 10_000, windowsHide: true });
      this.healthCache = { checkpoints: "ok" };
    } catch {
      this.healthCache = { checkpoints: "unavailable", checkpointReason: "git is not available" };
    }
    return this.healthCache;
  }

  async capture(input: CaptureInput): Promise<CheckpointRow> {
    const id = uuidv7();
    const label = input.label ?? "turn";
    const createdAt = Date.now();
    const failed = (error: string): CheckpointRow => {
      this.insert({ id, input, label, createdAt, treeSha: null, commitSha: null, notCaptured: 0, error });
      return this.row(input.sessionId, id);
    };
    const refusal = await this.refusal(input.workspaceRoot);
    if (refusal !== undefined) return failed(refusal);
    try {
      await this.ensureStore(input.workspaceId, input.workspaceRoot);
      await this.git(input.workspaceId, ["add", "-A", "--", "."]);
      const tree = (await this.git(input.workspaceId, ["write-tree"])).trim();
      const commit = (await this.git(input.workspaceId, ["commit-tree", tree, "-m", `checkpoint ${id}`])).trim();
      await this.git(input.workspaceId, ["update-ref", `refs/noir/${input.sessionId}/${id}`, commit]);
      const notCaptured = await this.countIgnored(input.workspaceId);
      this.insert({ id, input, label, createdAt, treeSha: tree, commitSha: commit, notCaptured, error: null });
      return this.row(input.sessionId, id);
    } catch (error) {
      return failed(error instanceof Error ? error.message : "checkpoint failed");
    }
  }

  row(sessionId: string, checkpointId: string): CheckpointRow {
    const row = this.db
      .prepare(
        `SELECT c.*, w.path FROM checkpoints c LEFT JOIN workspaces w ON w.id = c.workspace_id
           WHERE c.id = ? AND c.session_id = ?`,
      )
      .get(checkpointId, sessionId) as Row | undefined;
    if (row === undefined) throw new RpcFault(ErrorCodes.notFound, "Checkpoint not found");
    return {
      id: row.id, turnId: row.turn_id, seq: row.seq, createdAt: row.created_at,
      notCaptured: row.not_captured, label: row.label === "pre-restore" ? "pre-restore" : "turn",
      error: row.error, workspaceId: row.workspace_id, workspaceRoot: row.path,
      treeSha: row.tree_sha, commitSha: row.commit_sha,
    };
  }

  /** Re-reads the work tree into the store's index. The stat cache makes this a delta, not a walk. */
  async refresh(row: CheckpointRow): Promise<void> {
    await this.ensureStore(row.workspaceId, row.workspaceRoot);
    await this.git(row.workspaceId, ["add", "-A", "--", "."]);
  }

  private rows(sessionId: string): Row[] {
    return this.db
      .prepare("SELECT c.*, w.path FROM checkpoints c LEFT JOIN workspaces w ON w.id = c.workspace_id WHERE c.session_id = ? ORDER BY c.created_at ASC, c.id ASC")
      .all(sessionId) as Row[];
  }

  private storeDir(workspaceId: string): string {
    return join(this.opts.dataDir, "checkpoints", workspaceId);
  }

  private async git(workspaceId: string, args: string[]): Promise<string> {
    const result = await run(this.gitCommand, [...IDENTITY, "-C", this.storeDir(workspaceId), ...args], {
      timeout: GIT_TIMEOUT_MS,
      windowsHide: true,
      maxBuffer: 32 * 1024 * 1024,
      encoding: "utf8",
    });
    return result.stdout;
  }

  private async ensureStore(workspaceId: string, root: string): Promise<void> {
    const store = this.storeDir(workspaceId);
    await mkdir(store, { recursive: true });
    try {
      await stat(join(store, ".git"));
    } catch {
      await run(this.gitCommand, ["init", "--quiet", store], { timeout: GIT_TIMEOUT_MS, windowsHide: true });
    }
    const hooks = join(store, "hooks-disabled");
    const metadata = join(this.opts.dataDir, "checkpoints");
    const ignore = join(metadata, "ignore");
    await mkdir(hooks, { recursive: true });
    await mkdir(metadata, { recursive: true });
    // The store must never capture its own database or objects. `dataDir` is normally outside every
    // workspace, but a portable install can put it inside one, and then the first snapshot would
    // index the snapshot — so the path is excluded in work-tree-relative form when it is inside.
    const inside = relative(root, this.opts.dataDir);
    const self = inside !== "" && !inside.startsWith("..") && !isAbsolute(inside)
      ? [`/${inside.split(sep).join("/")}/`]
      : [];
    await writeFile(ignore, `${[...FORCED_EXCLUDES, ...self].join("\n")}\n`, "utf8");
    const settings: Array<[string, string]> = [
      ["core.worktree", root],
      ["core.bare", "false"],
      // A restore must write the bytes it read; this machine has autocrlf=true globally.
      ["core.autocrlf", "false"],
      ["core.safecrlf", "false"],
      ["core.hooksPath", hooks],
      ["core.fsmonitor", "false"],
      ["core.excludesFile", ignore],
    ];
    for (const [key, value] of settings) await this.git(workspaceId, ["config", key, value]);
  }

  /** Reasons a workspace is never snapshotted. Everything else is a per-turn error row. */
  private async refusal(root: string): Promise<string | undefined> {
    try {
      const attributes = await readFile(join(root, ".gitattributes"), "utf8");
      if (/filter\s*=\s*lfs/.test(attributes)) return "LFS worktrees are not supported";
    } catch {
      // No attributes file: nothing to refuse.
    }
    try {
      const stats = await statfs(this.opts.dataDir);
      if (Number(stats.bavail) * Number(stats.bsize) < MIN_FREE_BYTES) return "Not enough free space for a checkpoint";
    } catch {
      // No `statfs` on this platform: a snapshot is worth more than the space check.
    }
    return undefined;
  }

  private async countIgnored(workspaceId: string): Promise<number> {
    const out = await this.git(workspaceId, ["status", "--porcelain", "-z", "--ignored=matching", "--untracked-files=all"]);
    let count = 0;
    for (const entry of out.split("\u0000")) if (entry.startsWith("!! ")) count += 1;
    return Math.min(count, MAX_NOT_CAPTURED);
  }

  private insert(args: {
    id: string;
    input: CaptureInput;
    label: "turn" | "pre-restore";
    createdAt: number;
    treeSha: string | null;
    commitSha: string | null;
    notCaptured: number;
    error: string | null;
  }): void {
    this.db
      .prepare(
        `INSERT INTO checkpoints (id, workspace_id, session_id, turn_id, seq, tree_sha, commit_sha, label, created_at, not_captured, error)
         VALUES (?,?,?,?,?,?,?,?,?,?,?)`,
      )
      .run(
        args.id, args.input.workspaceId, args.input.sessionId, args.input.turnId, args.input.seq,
        args.treeSha, args.commitSha, args.label, args.createdAt, args.notCaptured, args.error,
      );
  }
}
```

```ts
  /** Paths a restore would write and paths it would delete, by git's own status class. */
  async changedPaths(row: CheckpointRow): Promise<{ modified: string[]; deleted: string[]; created: string[] }> {
    if (row.treeSha === null) throw new RpcFault(ErrorCodes.notFound, row.error ?? "Checkpoint has no tree");
    // `-z` because a quoted path would be written back verbatim: this machine's temp dirs and the
    // workspaces under them carry non-ASCII names. `--no-renames` keeps the output to a status/path pair.
    const out = await this.git(row.workspaceId, ["diff-index", "--name-status", "-z", "--no-renames", "--cached", row.treeSha]);
    const modified: string[] = [];
    const deleted: string[] = [];
    const created: string[] = [];
    const tokens = out.split("\u0000");
    for (let index = 0; index + 1 < tokens.length; index += 2) {
      const status = tokens[index] ?? "";
      const path = tokens[index + 1] ?? "";
      if (path === "") continue;
      // `D` is in the tree and gone from the work tree: it comes back. `A` exists only now: it goes.
      if (status === "D") deleted.push(path);
      else if (status === "A") created.push(path);
      else modified.push(path);
    }
    return { modified, deleted, created };
  }

  private async counts(row: CheckpointRow): Promise<CheckpointPlanResult> {
    const paths = await this.changedPaths(row);
    return {
      restored: paths.modified.length,
      deleted: paths.deleted.length,
      removed: paths.created.length,
      failed: [],
    };
  }

  async plan(sessionId: string, checkpointId: string): Promise<CheckpointPlanResult> {
    const row = this.row(sessionId, checkpointId);
    await this.refresh(row);
    return this.counts(row);
  }

  async restore(sessionId: string, checkpointId: string): Promise<CheckpointRestoreResult> {
    const row = this.row(sessionId, checkpointId);
    if (row.workspaceRoot === null || row.workspaceRoot === undefined) throw new RpcFault(ErrorCodes.notFound, "Workspace missing");
    if (row.treeSha === null) throw new RpcFault(ErrorCodes.notFound, row.error ?? "Checkpoint has no tree");
    await this.refresh(row);
    // What the user is about to lose becomes a checkpoint too, so a mistaken restore is one more
    // rewind away instead of a lost afternoon. Its seq is the one the marker is about to take, so
    // the range this rewind abandons ends exactly where the safety checkpoint starts.
    const safety = await this.capture({
      sessionId, workspaceId: row.workspaceId, workspaceRoot: row.workspaceRoot,
      turnId: null, seq: this.events.nextSeq(sessionId), label: "pre-restore",
    });
    // A rewind whose undo could not be taken is not a rewind: refuse rather than overwrite the work
    // tree with no way back.
    if (safety.error !== null) {
      throw new RpcFault(ErrorCodes.conflict, `The current state could not be captured: ${safety.error}`);
    }
    const plan = await this.counts(row);
    const paths = await this.changedPaths(row);
    const failed: string[] = [];

    // The index becomes the snapshot's tree; `checkout-index` then writes those bytes per path, so
    // one locked file is reported instead of aborting the whole restore.
    await this.git(row.workspaceId, ["read-tree", row.treeSha]);
    for (const path of [...paths.modified, ...paths.deleted]) {
      try {
        await this.git(row.workspaceId, ["checkout-index", "--force", "-z", "--stdin"], [path]);
      } catch {
        failed.push(path);
      }
    }
    for (const path of paths.created) {
      try {
        await rm(resolveInsideRoot(row.workspaceRoot, relativePath(path)), { force: true });
      } catch {
        failed.push(path);
      }
    }

    const session = this.db.prepare("SELECT agent_id, engine FROM sessions WHERE id = ?").get(sessionId) as
      | { agent_id: string; engine: EngineKind }
      | undefined;
    if (session === undefined) throw new RpcFault(ErrorCodes.notFound, "Session not found");
    const prompt = this.db
      .prepare(
        `SELECT seq FROM events WHERE session_id = ? AND seq >= ? AND type = 'message.delta'
           AND json_extract(payload_json, '$.role') = 'user' ORDER BY seq ASC LIMIT 1`,
      )
      .get(sessionId, row.seq) as { seq: number } | undefined;

    const event = this.events.append({
      sessionId,
      agentId: session.agent_id,
      type: "session.rewound",
      turnId: null,
      payload: {
        cutSeq: row.seq,
        checkpointId: row.id,
        promptSeq: prompt?.seq ?? null,
        restored: plan.restored,
        deleted: plan.deleted,
        removed: plan.removed,
        failed: failed.length,
        notCaptured: row.notCaptured,
        engine: session.engine,
        engineNotRewound: session.engine === "acp",
      },
      provenance: provenanceFor(session.engine),
    });
    return { ...plan, failed, ok: true, eventSeq: event.seq };
  }
```

```ts
import { useCallback, useEffect, useState } from "react";
import type { CheckpointListResult, CheckpointPlanResult } from "@noir/protocol";
import type { RequestFn } from "./api.js";
import { errorMessage } from "./events.js";

export interface CheckpointEntry {
  id: string;
  notCaptured: number;
  error: string | null;
}

export interface CheckpointsApi {
  byTurn: ReadonlyMap<string, CheckpointEntry>;
  available: boolean;
  reason: string | undefined;
  plan: (checkpointId: string) => Promise<CheckpointPlanResult>;
  restore: (checkpointId: string) => Promise<void>;
}

/**
 * The checkpoints of one session, keyed by turn. Refetched when `refreshKey` changes: a turn
 * starting is what adds a row, and only the kernel knows when that happened.
 */
export function useCheckpoints(sessionId: string, request: RequestFn, refreshKey: string): CheckpointsApi {
  const [list, setList] = useState<CheckpointListResult | undefined>(undefined);
  const [error, setError] = useState<string | undefined>(undefined);

  useEffect(() => {
    if (sessionId === "") return;
    let active = true;
    void (async () => {
      try {
        const result = await request<CheckpointListResult>("checkpoint.list", { sessionId });
        if (active) {
          setList(result);
          setError(undefined);
        }
      } catch (failure) {
        if (active) setError(errorMessage(failure));
      }
    })();
    return () => {
      active = false;
    };
  }, [sessionId, request, refreshKey]);

  const plan = useCallback(
    async (checkpointId: string): Promise<CheckpointPlanResult> =>
      request<CheckpointPlanResult>("checkpoint.plan", { sessionId, checkpointId }),
    [request, sessionId],
  );

  const restore = useCallback(
    async (checkpointId: string): Promise<void> => {
      await request("checkpoint.restore", { sessionId, checkpointId });
    },
    [request, sessionId],
  );

  const byTurn = new Map<string, CheckpointEntry>();
  for (const entry of list?.checkpoints ?? []) {
    if (entry.turnId !== null && entry.error === null) {
      byTurn.set(entry.turnId, { id: entry.id, notCaptured: entry.notCaptured, error: entry.error });
    }
  }

  return {
    byTurn,
    available: list?.available === true && error === undefined,
    reason: list?.reason ?? error,
    plan,
    restore,
  };
}
```

`RequestFn` is declared in `api.ts`; `CheckpointListResult`/`CheckpointPlanResult` are exported from `@noir/protocol` — import them from there if `api.ts` does not re-export them.

```ts
/** One line of the transcript. A rewind and a message share one ordering, by seq. */
export interface TranscriptRow {
  seq: number;
  message?: ChatMessage;
  rewind?: ChatRewind;
  turnId?: string;
}

export function transcriptRows(state: ChatState): TranscriptRow[] {
  return [
    ...state.messages.map((message) => ({
      seq: message.seq ?? Number.MAX_SAFE_INTEGER,
      message,
      ...(message.turnId === undefined ? {} : { turnId: message.turnId }),
    })),
    ...state.rewinds.map((rewind) => ({ seq: rewind.seq, rewind })),
  ].sort((left, right) => left.seq - right.seq);
}
```

```tsx
    setRewindPlan(undefined);
```

```md
## Rewind

Every turn starts by snapshotting the workspace into a hidden git repository under the data
directory (`.noir/checkpoints/<workspace>/`), never into your own `.git`. Hover a message you
sent, choose **Rewind to before this prompt**, and the app shows what would move before it moves
anything: modified and deleted files come back, files the turn created are removed, and the
conversation after that prompt disappears.

- Build outputs, `node_modules`, and the directories in the store's own ignore file are never
  captured or moved. Anything your `.gitignore` hides stays on disk untouched.

- `session.rewound` is appended, never inserted: the log stays append-only and every seq keeps

- The native engine is disposed and its history is rebuilt from the visible log. An ACP engine
  keeps its own memory, so the marker says it was not rewound; the workspace and the transcript
  still are.
- LFS work trees are refused, as is a disk with less than 500 MiB free. `git` must be on `PATH`
  (or named by `NOIR_GIT_COMMAND`); `system.health` reports it as `checkpoints`.
```
