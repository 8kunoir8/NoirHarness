# M3.2 Skill Registry Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Install a skill from an `https` git URL or a local directory, pin it to a commit plus a content hash, show where it came from, update it only against the hash the user was shown, and remove it cleanly.

**Architecture:** A new kernel module `skillSources.ts` owns fetching and staging; `skills.ts` stays the owner of discovery and materialization and lends it `hashSkillDir`, `SKILL_NAME`, and the existing caps. Provenance lives in one `skill_sources` table keyed the same way as `skills` (`workspace_id`, `scope`, `name`), so a hand-placed skill simply has no row. Four RPC methods drive it; the Skills panel gains an install control and a per-row source line.

**Tech Stack:** TypeScript strict ESM, `better-sqlite3`, `node:child_process` `execFile`, `node:fs/promises`, Zod protocol schemas, React 19 + Testing Library, Vitest.

**Spec:** `docs/superpowers/specs/2026-11-12-m3.2-skill-registry-design.md`

## Global Constraints

- Node >= 24, pnpm >= 10, TS strict with `noUncheckedIndexedAccess` and `exactOptionalPropertyTypes`.
- ESM with `.js` import extensions; no new runtime npm dependencies.
- Follow the existing conventions: tool/service failures return values, they are not thrown, except `RpcFault` at the RPC boundary.
- Static string-keyed lookups are `Record<string, true>`, never `Set`.
- Prefer `Promise.withResolvers()` over `new Promise(executor)`.
- One commit per task on `main`; never branch, never push.
- Windows-first: paths use `node:path`, never string concatenation; directory rename-aside is required because renaming over a non-empty directory fails on NTFS.
- Test commands: `pnpm --filter @noir/kernel test`, `pnpm --filter @noir/kernel test skills`, `pnpm --filter @noir/protocol test`, `cd apps/desktop && pnpm test`, `pnpm -r typecheck`.

## Review Focus

1. **A URL that looks like a local Windows path.** `new URL("C:\\tmp\\x")` yields protocol `c:`. A `local` source must never be parsed as a URL, and a `git` source must never be a bare path — the two kinds are separate fields and neither falls back to the other.
2. **A hostname that only starts with a loopback address.** `http://127.0.0.1.evil/x` parses with hostname `127.0.0.1.evil`. The loopback test compares the whole hostname against an exact allowlist, never a prefix.
3. **An update fetched between the check and the write.** The pin is `expectHash` passed by the caller and compared to the freshly fetched hash; there is no "check then update" gap, and a mismatch writes nothing.
4. **A skill name from untrusted `SKILL.md`.** `../../x` or `a/b` must be refused before any `join()`, since the name becomes a directory name in two roots.
5. **A failed update mid-copy.** The previous directory and the previous source row must both survive; a half-written skill directory must not be left in a scanned root.

```ts
import { lstat } from "node:fs/promises";
import { isAbsolute } from "node:path";
import { ErrorCodes, RpcFault } from "@noir/protocol";

export type FetchTarget =
  | { kind: "git"; url: string; ref: string | undefined }
  | { kind: "local"; path: string };

/** Hostnames that may be reached over plain `http`. A whole-host comparison, never a prefix. */
const LOOPBACK_HOSTS: Record<string, true> = { "127.0.0.1": true, localhost: true, "[::1]": true };
const REF = /^[A-Za-z0-9][A-Za-z0-9._/-]{0,127}$/;

export function parseGitTarget(source: string, ref: string | undefined): FetchTarget {
  if (ref !== undefined && !REF.test(ref)) throw new RpcFault(ErrorCodes.invalidParams, `Invalid ref: ${ref}`);
  let url: URL;
  try {
    url = new URL(source);
  } catch {
    throw new RpcFault(ErrorCodes.invalidParams, `${source} is not a URL`);
  }
  // `ext::` reaches a remote command; `C:\x` parses as protocol `c:`; both fall out here.
  const loopback = LOOPBACK_HOSTS[url.hostname] === true;
  if (url.protocol !== "https:" && !(url.protocol === "http:" && loopback)) {
    throw new RpcFault(ErrorCodes.invalidParams, `${url.protocol} is not an accepted transport`);
  }
  if (url.username !== "" || url.password !== "") {
    throw new RpcFault(ErrorCodes.invalidParams, "A skill source URL must not carry credentials");
  }
  return { kind: "git", url: url.href, ref };
}

/** Resolves a `local` target to a real directory; a link is refused rather than followed. */
export async function parseLocalTarget(source: string): Promise<FetchTarget> {
  if (!isAbsolute(source)) throw new RpcFault(ErrorCodes.invalidParams, "A local skill source must be an absolute path");
  const marker = await lstat(source).catch((error: unknown) => {
    if ((error as NodeJS.ErrnoException).code === "ENOENT") {
      throw new RpcFault(ErrorCodes.invalidParams, `${source} is not a directory`);
    }
    throw error;
  });
  if (marker.isSymbolicLink()) throw new RpcFault(ErrorCodes.invalidParams, `${source} is a symlink`);
  if (!marker.isDirectory()) throw new RpcFault(ErrorCodes.invalidParams, `${source} is not a directory`);
  return { kind: "local", path: source };
}
```

```ts
// packages/kernel/test/smartHttp.ts
import { spawn, spawnSync } from "node:child_process";
import { mkdirSync, writeFileSync } from "node:fs";
import { createServer, type Server } from "node:http";
import { join } from "node:path";

/** Runs git with a fixed identity, so a fixture never depends on the machine's git config. */
export const git = (cwd: string, args: string[]): string => {
  const result = spawnSync("git", ["-c", "user.email=a@b.c", "-c", "user.name=t", ...args], { cwd, encoding: "utf8" });
  if (result.status !== 0) throw new Error(`git ${args.join(" ")}: ${result.stderr}`);
  return result.stdout;
};

/** A repo at `dir` containing one skill directory, committed. */
export function skillRepo(dir: string, name: string, body = "BODY"): void {
  mkdirSync(join(dir, name), { recursive: true });
  writeFileSync(join(dir, name, "SKILL.md"), `---\nname: ${name}\ndescription: d\n---\n\n${body}\n`);
  git(dir, ["init", "-q", "-b", "main", "."]);
  git(dir, ["add", "-A"]);
  git(dir, ["commit", "-qm", "one"]);
}

/**
 * Serves `bareDir` over the smart protocol. The dumb protocol cannot clone `--depth 1`, so the
 * fixture must go through `git http-backend`.
 */
export async function serveSmartHttp(bareDir: string): Promise<{ url: string; close: () => Promise<void> }> {
  const server: Server = createServer((req, res) => {
    const url = new URL(req.url ?? "/", "http://placeholder");
    const child = spawn("git", ["http-backend"], {
      env: {
        ...process.env,
        GIT_PROJECT_ROOT: bareDir,
        GIT_HTTP_EXPORT_ALL: "1",
        PATH_INFO: url.pathname,
        QUERY_STRING: url.search.slice(1),
        REQUEST_METHOD: req.method ?? "GET",
        CONTENT_TYPE: String(req.headers["content-type"] ?? ""),
        GIT_PROTOCOL: String(req.headers["git-protocol"] ?? ""),
        CONTENT_LENGTH: String(req.headers["content-length"] ?? ""),
      },
    });
    req.pipe(child.stdin);
    let headersDone = false;
    let buffer = Buffer.alloc(0);
    child.stdout.on("data", (chunk: Buffer) => {
      if (headersDone) return void res.write(chunk);
      buffer = Buffer.concat([buffer, chunk]);
      const end = buffer.indexOf("\r\n\r\n");
      if (end === -1) return;
      headersDone = true;
      let status = 200;
      const headers: Record<string, string> = {};
      for (const line of buffer.subarray(0, end).toString().split("\r\n")) {
        const separator = line.indexOf(":");
        if (separator === -1) continue;
        const key = line.slice(0, separator);
        const value = line.slice(separator + 1).trim();
        if (key.toLowerCase() === "status") status = Number(value.split(" ")[0]);
        else headers[key] = value;
      }
      res.writeHead(status, headers);
      res.write(buffer.subarray(end + 4));
    });
    child.on("close", () => {
      if (!headersDone) res.writeHead(500);
      res.end();
    });
  });
  await new Promise<void>((resolve) => server.listen(0, "127.0.0.1", resolve));
  const address = server.address() as { port: number };
  return {
    url: `http://127.0.0.1:${address.port}/`,
    close: () => new Promise<void>((resolve) => server.close(() => resolve())),
  };
}
```

```ts
const GIT_TIMEOUT_MS = 30_000;
const MAX_ENTRIES = 2000;
const MAX_CLONE_BYTES = 32 * 1024 * 1024;

export interface FetchedSource {
  dir: string;
  name: string;
  description: string;
  hash: string;
  commit: string | null;
  cleanup: () => Promise<void>;
}

async function gitAt(cwd: string, args: string[]): Promise<string> {
  const result = await run(gitCommand(), ["-c", "protocol.ext.allow=never", "-c", "core.symlinks=false", ...args], {
    cwd,
    timeout: GIT_TIMEOUT_MS,
    maxBuffer: 4 * 1024 * 1024,
    windowsHide: true,
    encoding: "utf8",
    env: { ...process.env, GIT_TERMINAL_PROMPT: "0", GIT_ASKPASS: "", GIT_ASKPASS_REQUIRE: "never" },
  }).catch((error: unknown) => {
    const failure = error as { stderr?: string; message?: string };
    throw new RpcFault(ErrorCodes.internal, (failure.stderr ?? failure.message ?? "git failed").slice(0, 2048));
  });
  return result.stdout;
}

async function measure(dir: string): Promise<{ files: number; bytes: number }> {
  let files = 0;
  let bytes = 0;
  const walk = async (current: string): Promise<void> => {
    for (const entry of await readdir(current, { withFileTypes: true })) {
      if (entry.isSymbolicLink()) continue;
      const absolute = join(current, entry.name);
      if (entry.isDirectory()) await walk(absolute);
      else if (entry.isFile()) {
        files += 1;
        bytes += (await stat(absolute)).size;
        if (files > MAX_ENTRIES) throw new Error(`more than ${MAX_ENTRIES} files`);
        if (bytes > MAX_CLONE_BYTES) throw new Error(`more than ${MAX_CLONE_BYTES} bytes`);
      }
    }
  };
  await walk(dir);
  return { files, bytes };
}

/** Reads the skill manifest of a staged directory, refusing a name that could escape a root. */
async function readStagedSkill(dir: string): Promise<{ name: string; description: string; hash: string }> {
  const file = join(dir, "SKILL.md");
  const marker = await lstat(file);
  if (!marker.isFile() || marker.isSymbolicLink()) throw new RpcFault(ErrorCodes.invalidParams, "SKILL.md is not a regular file");
  if (marker.size > MAX_SKILL_FILE_BYTES) throw new RpcFault(ErrorCodes.invalidParams, "SKILL.md is larger than 1 MiB");
  const front = parseSkillFrontmatter(await readFile(file, "utf8"));
  if (front.name === undefined) throw new RpcFault(ErrorCodes.invalidParams, "SKILL.md has no name");
  // The name becomes a directory name in two roots, so it is validated before any join.
  if (!SKILL_NAME.test(front.name)) throw new RpcFault(ErrorCodes.invalidParams, `"${front.name}" is not a valid skill name`);
  if (front.description === undefined) throw new RpcFault(ErrorCodes.invalidParams, "SKILL.md has no description");
  const measured = await measure(dir);
  if (measured.files > MAX_SKILL_FILES) throw new RpcFault(ErrorCodes.invalidParams, `more than ${MAX_SKILL_FILES} files`);
  if (measured.bytes > MAX_SKILL_BYTES) throw new RpcFault(ErrorCodes.invalidParams, `more than ${MAX_SKILL_BYTES} bytes`);
  return { name: front.name, description: front.description, hash: await hashSkillDir(dir) };
}

export async function fetchSkill(target: FetchTarget, stagingRoot: string): Promise<FetchedSource> {
  const staging = join(stagingRoot, uuidv7());
  await mkdir(staging, { recursive: true });
  const cleanup = () => rm(staging, { recursive: true, force: true });
  try {
    let checkout: string;
    let commit: string | null = null;
    if (target.kind === "git") {
      const args = ["clone", "--depth", "1", "--no-recurse-submodules", "--single-branch"];
      if (target.ref !== undefined) args.push("--branch", target.ref);
      args.push("--", target.url, join(staging, "checkout"));
      await gitAt(staging, args);
      checkout = join(staging, "checkout");
      commit = (await gitAt(checkout, ["rev-parse", "HEAD"])).trim();
      await rm(join(checkout, ".git"), { recursive: true, force: true });
    } else {
      checkout = join(staging, "checkout");
      await mkdir(checkout, { recursive: true });
      for (const entry of await readdir(target.path, { withFileTypes: true })) {
        if (entry.isSymbolicLink()) continue;
        await cp(join(target.path, entry.name), join(checkout, entry.name), { recursive: entry.isDirectory() });
      }
    }
    await measure(checkout);
    const read = await readStagedSkill(checkout);
    return { dir: checkout, name: read.name, description: read.description, hash: read.hash, commit, cleanup };
  } catch (error) {
    await cleanup();
    throw error;
  }
}
```

```ts
import type Database from "better-sqlite3";
import type { SkillScope, SkillService } from "./skills.js";
import type { SkillSourceView } from "@noir/protocol";

interface SourceRow {
  workspace_id: string;
  scope: SkillScope;
  name: string;
  kind: "git" | "local";
  url: string | null;
  ref: string | null;
  commit_sha: string | null;
  hash: string;
}

export class SkillSourceService {
  constructor(
    private readonly db: Database.Database,
    private readonly skills: SkillService,
    private readonly dataDir: string,
  ) {}

  private get stagingRoot(): string {
    return join(this.dataDir, "skill-staging");
  }

  private row(workspaceId: string, scope: SkillScope, name: string): SourceRow | undefined {
    return this.db
      .prepare(
        "SELECT workspace_id, scope, name, kind, url, ref, commit_sha, hash FROM skill_sources " +
          "WHERE workspace_id = ? AND scope = ? AND name = ?",
      )
      .get(scope === "global" ? "" : workspaceId, scope, name) as SourceRow | undefined;
  }

  /** Every provenance row visible to one workspace, keyed `"<scope>|<name>"`. */
  sourcesFor(workspaceId: string): Map<string, SkillSourceView> {
    const rows = this.db
      .prepare(
        "SELECT workspace_id, scope, name, kind, url, ref, commit_sha, hash FROM skill_sources WHERE workspace_id IN ('', ?)",
      )
      .all(workspaceId) as SourceRow[];
    const map = new Map<string, SkillSourceView>();
    for (const row of rows) {
      const visible = row.workspace_id === "" ? row.scope === "global" : row.scope === "project";
      if (!visible) continue;
      map.set(`${row.scope}|${row.name}`, {
        kind: row.kind,
        url: row.url ?? "",
        ref: row.ref,
        commit: row.commit_sha,
        hash: row.hash,
      });
    }
    return map;
  }

  private record(workspaceId: string, scope: SkillScope, name: string, target: FetchTarget, fetched: FetchedSource): void {
    this.db
      .prepare(
        "INSERT INTO skill_sources (id, workspace_id, scope, name, kind, url, ref, commit_sha, hash, installed_at) " +
          "VALUES (?,?,?,?,?,?,?,?,?,?) ON CONFLICT (workspace_id, scope, name) DO UPDATE SET " +
          "kind = excluded.kind, url = excluded.url, ref = excluded.ref, commit_sha = excluded.commit_sha, " +
          "hash = excluded.hash, installed_at = excluded.installed_at",
      )
      .run(
        uuidv7(),
        scope === "global" ? "" : workspaceId,
        scope,
        name,
        target.kind,
        target.kind === "git" ? target.url : target.path,
        target.kind === "git" ? (target.ref ?? null) : null,
        fetched.commit,
        fetched.hash,
      );
  }

  async install(
    workspaceId: string, root: string | undefined, scope: SkillScope, kind: "git" | "local", source: string, ref: string | undefined,
  ): Promise<{ name: string; hash: string }> {
    const target: FetchTarget = kind === "local" ? await parseLocalTarget(source) : parseGitTarget(source, ref);
    const destination = await this.skills.rootFor(workspaceId, scope, root);
    const fetched = await fetchSkill(target, this.stagingRoot);
    try {
      const existing = await lstat(join(destination, fetched.name)).catch(() => undefined);
      if (existing !== undefined) {
        throw new RpcFault(ErrorCodes.conflict, `${fetched.name} is already installed in ${scope}; update it instead`);
      }
      await this.place(fetched.dir, join(destination, fetched.name));
      this.record(workspaceId, scope, fetched.name, target, fetched);
      if (root !== undefined) await this.skills.materialize(workspaceId, root);
      return { name: fetched.name, hash: fetched.hash };
    } finally {
      await fetched.cleanup();
    }
  }

  /** Copies a staged directory into a root through a temp sibling and a rename, never a partial write. */
  private async place(staged: string, destination: string): Promise<void> {
    const temp = `${destination}.installing-${uuidv7()}`;
    await cp(staged, temp, { recursive: true, errorOnExist: false });
    await rename(temp, destination).catch(async (error: unknown) => {
      await rm(temp, { recursive: true, force: true });
      throw error;
    });
  }

  async checkUpdate(workspaceId: string, scope: SkillScope, name: string): Promise<{ commit: string | null; hash: string; changed: boolean }> {
    const row = this.row(workspaceId, scope, name);
    if (row === undefined) throw new RpcFault(ErrorCodes.notFound, `${name} was not installed from a source`);
    const target = await this.targetOf(row);
    const fetched = await fetchSkill(target, this.stagingRoot);
    try {
      const commit = fetched.commit;
      const changed = fetched.hash !== row.hash || (commit !== null && commit !== row.commit_sha);
      return { commit, hash: fetched.hash, changed };
    } finally {
      await fetched.cleanup();
    }
  }

  async update(
    workspaceId: string, root: string | undefined, scope: SkillScope, name: string, expectHash: string,
  ): Promise<{ commit: string | null; hash: string }> {
    const row = this.row(workspaceId, scope, name);
    if (row === undefined) throw new RpcFault(ErrorCodes.notFound, `${name} was not installed from a source`);
    const target = await this.targetOf(row);
    const fetched = await fetchSkill(target, this.stagingRoot);
    try {
      if (fetched.hash !== expectHash) {
        throw new RpcFault(ErrorCodes.conflict, `${name} changed since it was shown: expected ${expectHash}, fetched ${fetched.hash}`);
      }
      const destination = join(await this.skills.rootFor(workspaceId, scope, root), name);
      const aside = `${destination}.previous-${uuidv7()}`;
      let moved = false;
      try {
        await rename(destination, aside);
        moved = true;
      } catch (error) {
        if ((error as NodeJS.ErrnoException).code !== "ENOENT") throw error;
      }
      try {
        await this.place(fetched.dir, destination);
      } catch (error) {
        if (moved) await rename(aside, destination).catch(() => undefined);
        throw error;
      }
      if (moved) await rm(aside, { recursive: true, force: true });
      this.record(workspaceId, scope, name, target, fetched);
      if (root !== undefined) await this.skills.materialize(workspaceId, root);
      return { commit: fetched.commit, hash: fetched.hash };
    } finally {
      await fetched.cleanup();
    }
  }

  async remove(workspaceId: string, root: string | undefined, scope: SkillScope, name: string): Promise<void> {
    if (!SKILL_NAME.test(name)) throw new RpcFault(ErrorCodes.invalidParams, `"${name}" is not a valid skill name`);
    const destination = join(await this.skills.rootFor(workspaceId, scope, root), name);
    await rm(destination, { recursive: true, force: true });
    this.db
      .prepare("DELETE FROM skill_sources WHERE workspace_id = ? AND scope = ? AND name = ?")
      .run(scope === "global" ? "" : workspaceId, scope, name);
    this.db
      .prepare("DELETE FROM skills WHERE workspace_id = ? AND scope = ? AND name = ?")
      .run(scope === "global" ? "" : workspaceId, scope, name);
    if (root !== undefined) await this.skills.materialize(workspaceId, root);
  }

  private async targetOf(row: SourceRow): Promise<FetchTarget> {
    if (row.kind === "local") return parseLocalTarget(row.url ?? "");
    return parseGitTarget(row.url ?? "", row.ref ?? undefined);
  }
}
```

## Self-Review
**Fixes made during this self-review** (each was a defect in an earlier draft of this plan, not in
the codebase):

- The git fixture used `require` inside an ESM test.
- `--depth 1` over the dumb protocol was measured to fail, so the fixture serves smart HTTP through
  `git http-backend`, and §5.1 of the spec now allows `http:` on loopback to match.
- `GIT` was read at module load, which made the "no process spawned" test vacuous. It is read per
  call, and that test now points the binary at a marker script.
- Task 2's test required a mid-task signature change. It is two functions from the start.
- Task 5's test invented a `client.call` harness that does not exist; it now uses the file's real
  `startKernel` and `call(port, token, method, params)`, and creates a workspace first.
- The UI's `source: kind === "git" ? value : value` was a tautology, and both branches were wrong.
- `rename` was used without being imported, and `place` renamed onto an existing destination, which
  fails on NTFS; it now copies to a temp sibling that is removed on failure.

**Coverage.** §3 → Task 1. §4 → Tasks 4, 5. §5.1 → Task 2. §5.2 and §5.3 → Task 3. §5.4 →
Task 3 (`readStagedSkill`) and Task 4 (`remove`). §6 → Tasks 2–4. §7 → no code, by design: install
is user-initiated and raises no approval card, so there is nothing to test. §8 → Tasks 5, 6.
§9 → each listed case appears in the owning task. §10 → no code.

**Type consistency.** `FetchedSource.dir` is a staging path; `place` copies it and `cleanup` removes
it, so no caller retains it past its `finally`. `rootFor` is async everywhere. `sourcesFor` is
synchronous in its signature and at its call site. `SkillSourceView.url` is non-nullable while the
column is nullable, so `sourcesFor` maps `null` to `""`; a `local` row always has a path because
`record` writes one.

**Review Focus coverage.** (1) `C:\x` parses as protocol `c:` — Task 2 refuses it as a git source,
and the UI classifies a path by pattern rather than parsing it as a URL. (2) `127.0.0.1.evil` —
Task 2 asserts refusal. (3) the check-then-write gap — Task 4 asserts a stale `expectHash` refuses
and leaves bytes identical. (4) `../../escape` — Task 4 asserts the fetch refuses it and nothing is
created outside the root. (5) a failed update mid-copy — `update` renames the old directory aside
before placing the new one and restores it on failure; a portable fixture cannot induce a mid-copy
filesystem failure, so that restore branch is reviewed rather than tested.

**Known weakness, stated plainly.** A `local` source has no version to move: `checkUpdate` compares
the hash of a re-copied directory, so `commit` is `null` and only `hash` can differ. That is the
honest behavior of a directory without history.

## Post-implementation corrections

Applied after the milestone landed, each because the plan's shape could not survive contact with
the constraint it was written against. The snippets above are updated to match.

- **`updateAvailable` was removed from `SkillSourceView`.** The kernel could never set it true
  (`list` must not touch the network), so it was a permanently-false field that both UI readers
  stripped. The badge is the pin map alone.
- **`skill.remove` returns the listing**, `SkillListResult.extend({ ok: true })`, not `{ ok }` alone:
  removing the project copy of a name unshadows the global one.
- **`SkillScan.shadowed` carries `{ name, dir }`.** The wire shape is still `string[]`, but a
  shadowed skill's directory need not be named after it, and `dirFor` — the single resolution point
  for install's conflict check and for `remove` — must not guess.
- **`dirFor` refuses an unreadable workspace** rather than reporting the skill absent, so a delete
  can never act on files it did not look at.
- **Scratch siblings are reaped**, not only tolerated: `isStaleSibling` keeps
  `<name>.(installing|previous)-<uuid>` out of the scan, and the write paths delete them.

**Known gap.** A shadowed global can be removed over RPC (its directory comes from the scan), but
the panel renders a shadowed entry as an informational row with no controls. Removing the project
copy first is the only path a user has. Not built here: the shadowed row would need its own source
and scope controls, which the current row layout has no space for.
