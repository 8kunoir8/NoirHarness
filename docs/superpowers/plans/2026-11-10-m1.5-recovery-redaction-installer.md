# M1.5 Crash Recovery, Redaction, Installer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A crashed kernel restarts to an explicit `error` session that resumes on the next prompt, secrets never reach persisted events, and a Windows installer runs the packaged app with its own Node runtime and kernel.

**Architecture:** Recovery stays in `EngineManager`: a startup sweep fails orphaned turns/approvals and moves `starting|running|waiting` sessions to `error("kernel_restart")`; the composer already accepts prompts from `error`. Redaction is a pure `Redactor` applied inside `EventStore.append` before schema validation, seeded from provider vault keys, sensitive environment values, built-in token shapes, and `NOIR_REDACT_PATTERNS`. Packaging stages the bundled kernel plus a copied Node binary as `extraResources`; Electron main selects those paths when `app.isPackaged`.

**Tech Stack:** TypeScript strict ESM, better-sqlite3, zod, React 19, Vitest, Playwright Electron, electron-builder 26 (NSIS), pnpm deploy staging.

**Spec:** `docs/superpowers/specs/2026-11-09-noirharness-design.md` (§4.1 redaction at ingest, §6 lifecycle recovery, §9 security, §13 M1.5)

## Global Constraints

- Node ≥24, pnpm ≥10; TypeScript strict with `noUncheckedIndexedAccess` and `exactOptionalPropertyTypes`; ESM imports end in `.js` on the server side.
- Windows-first; paths with spaces and non-ASCII must work.
- Kernel is the only fs/DB authority; every RPC parses its zod schema before use.
- Events are immutable; append + projection happen in one transaction; replay must reproduce state.
- Never use `python`/`sed` for edits; SDD scripts run through `"C:/Program Files/Git/usr/bin/bash.exe"`.
- Never create another branch, never push, one commit per task (`feat|test|docs|fix`).
- Playwright `getByLabel` is case-insensitive → use `{ exact: true }`. Desktop Vitest has no jest-dom.
- Per-call `model` is disabled for `task` calls here — omit `model`.
- E2E: `pnpm --filter @noir/desktop test:e2e` rebuilds dist and drops trailing `--grep`.

## Review Focus

1. A provider key split across two streaming `message.delta` events: per-event redaction cannot join them, so a key straddling the boundary can leak in two harmless-looking halves. The full-key case is pinned in Task 3; Task 4 must not claim chunk-boundary safety.
2. A crash while an approval is pending: after restart the approval must be rejected, its turn failed, and the session `error` — not left `waiting` forever. Pinned in Task 1.
3. A crash during `EventStore.append`: SQLite must keep event and projection atomic; reopening the DB must show either both or neither. Pinned in Task 3.
4. Resume after the provider/model was deleted or disabled during the crash window: the prompt must surface an error and leave no zombie `running` status. Pinned in Task 5.
5. Installer under an install path containing spaces and non-ASCII characters, on a machine without a global Node: the bundled runtime must spawn the kernel. Pinned in Task 6.

`packages/kernel/src/redact.ts`:

```ts
export const REDACTED = "[REDACTED]";
const MIN_SECRET_LENGTH = 8;
const MAX_SECRETS = 512;
const MAX_DEPTH = 32;

const BUILTIN_PATTERNS: readonly RegExp[] = [
  /\bsk-[A-Za-z0-9_-]{16,}\b/g,
  /\bsk-ant-[A-Za-z0-9_-]{16,}\b/g,
  /(?<=\bBearer\s+)[A-Za-z0-9._~+/=-]{8,}/g,
  /\bAKIA[0-9A-Z]{16}\b/g,
  /\bgh[pousr]_[A-Za-z0-9]{20,}\b/g,
  /\bgithub_pat_[A-Za-z0-9_]{20,}\b/g,
  /\bxox[baprs]-[A-Za-z0-9-]{10,}\b/g,
  /\bAIza[0-9A-Za-z_-]{35}\b/g,
  /-----BEGIN [A-Z ]*PRIVATE KEY-----[\s\S]*?-----END [A-Z ]*PRIVATE KEY-----/g,
];

const ENV_SECRET_NAME = /(?:^|_)(?:API_?KEY|KEY|TOKEN|SECRET|PASSWORD|PASSWD|CREDENTIALS?|AUTH)$/i;

export function environmentSecrets(env: NodeJS.ProcessEnv): string[] {
  const values: string[] = [];
  for (const [name, value] of Object.entries(env)) {
    if (value === undefined || value.length < MIN_SECRET_LENGTH) continue;
    if (ENV_SECRET_NAME.test(name)) values.push(value);
  }
  return values;
}

export function parseRedactionPatterns(raw: string | undefined): RegExp[] {
  if (raw === undefined || raw.trim() === "") return [];
  let parsed: unknown;
  try { parsed = JSON.parse(raw); } catch { throw new Error("NOIR_REDACT_PATTERNS must be a JSON array of regex sources"); }
  if (!Array.isArray(parsed)) throw new Error("NOIR_REDACT_PATTERNS must be a JSON array of regex sources");
  return parsed.map((entry) => {
    if (typeof entry !== "string") throw new Error(`Invalid NOIR_REDACT_PATTERNS entry: ${String(entry)}`);
    try { return new RegExp(entry, "g"); } catch { throw new Error(`Invalid NOIR_REDACT_PATTERNS entry: ${entry}`); }
  });
}

export class Redactor {
  private secrets: string[] = [];
  private readonly patterns: RegExp[];
  constructor(opts: { secrets?: Iterable<string>; patterns?: Iterable<RegExp>; env?: NodeJS.ProcessEnv } = {}) {
    const initial = [...(opts.secrets ?? []), ...environmentSecrets(opts.env ?? {})];
    for (const secret of initial) this.addSecret(secret);
    this.patterns = [...BUILTIN_PATTERNS, ...(opts.patterns ?? [])];
  }
  addSecret(value: string | null | undefined): void {
    if (value === null || value === undefined) return;
    const secret = value.trim();
    if (secret.length < MIN_SECRET_LENGTH || this.secrets.length >= MAX_SECRETS || this.secrets.includes(secret)) return;
    this.secrets.push(secret);
    this.secrets.sort((a, b) => b.length - a.length);
  }
  redactText(text: string): string {
    let out = text;
    for (const secret of this.secrets) out = out.split(secret).join(REDACTED);
    for (const pattern of this.patterns) {
      pattern.lastIndex = 0;
      out = out.replace(pattern, REDACTED);
    }
    return out;
  }
  redact(value: unknown, depth = 0): unknown {
    if (depth > MAX_DEPTH) return value;
    if (typeof value === "string") return this.redactText(value);
    if (Array.isArray(value)) return value.map((item) => this.redact(item, depth + 1));
    if (value !== null && typeof value === "object") {
      const out: Record<string, unknown> = {};
      for (const [key, item] of Object.entries(value)) out[key] = this.redact(item, depth + 1);
      return out;
    }
    return value;
  }
}
```

/** SIGKILLs the kernel recorded in `<dataDir>/runtime/kernel.json` and waits for it to be gone. */
export async function killKernel(dataDir: string): Promise<void> {
  const pid = readRuntimePid(join(dataDir, "runtime", "kernel.json"));
  if (pid === undefined) throw new Error("no kernel pid recorded");
  process.kill(pid, "SIGKILL");
  await waitForKernelExit(dataDir);
}
```

import { cpSync, existsSync, mkdirSync, rmSync } from "node:fs";
import { dirname, join } from "node:path";
import { fileURLToPath } from "node:url";
import { spawnSync } from "node:child_process";

const appDir = dirname(dirname(fileURLToPath(import.meta.url)));
const root = dirname(dirname(appDir));
const staging = join(root, "build");
rmSync(staging, { recursive: true, force: true });
mkdirSync(staging, { recursive: true });

const pnpm = process.platform === "win32" ? "pnpm.cmd" : "pnpm";
const deploy = spawnSync(pnpm, ["--filter", "@noir/app-kernel", "deploy", "--prod", "--legacy", join(staging, "kernel")], {
  cwd: root, stdio: "inherit", shell: process.platform === "win32",
});
if (deploy.status !== 0) process.exit(deploy.status ?? 1);
if (!existsSync(join(staging, "kernel", "dist", "index.cjs"))) throw new Error("deployed kernel is missing dist/index.cjs");
if (!existsSync(join(staging, "kernel", "node_modules", "better-sqlite3"))) throw new Error("deployed kernel is missing better-sqlite3");

mkdirSync(join(staging, "runtime"), { recursive: true });
cpSync(process.execPath, join(staging, "runtime", process.platform === "win32" ? "node.exe" : "node"));
```
