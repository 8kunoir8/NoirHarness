# M4.0 Automation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scheduled agent runs inside the running app — a schedule is a row, a run is an ordinary session tagged with its schedule, and one injected-clock timer fires the due ones.

**Architecture:** Four new units, each with one job. `cadence.ts` is pure arithmetic: step a local wall-clock instant forward. `ScheduleService` owns the two tables and every read/write of them. `Scheduler` owns the clock, the single armed timer, and the fire decision; it is fully synchronous — it creates the session and kicks the prompt without waiting for a turn, so one slow turn cannot stall the timer. `index.ts` wires them and exposes six RPC methods. The desktop panel is the only UI surface.

**Tech Stack:** TypeScript 5.9 ESM, better-sqlite3 (sync), zod, uuid v7, vitest, React 19 + @testing-library/react. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-13-m4.0-automation-design.md`

## Global Constraints

- Node `>= 24`, pnpm `>= 10`. TypeScript strict with `noUncheckedIndexedAccess` and `exactOptionalPropertyTypes`.
- ESM: every relative import ends in `.js`.
- **Zero new runtime dependencies.** No cron library, no date library.
- Service-boundary failures are `RpcFault(ErrorCodes.<code>, msg)`: `invalidParams` for argument-shaped, `conflict` for name-exists/already-running, `notFound` for absent rows, `internal` for git/network/fs-atomicity.
- Static string-keyed lookups are `Record<string, true>`, never `Set`.
- Migrations are append-only: add id `9`; never edit ids `1`–`8`.
- One commit per task on `main`. Never branch, never push, never amend.
- Commit messages use `git commit -F -` with a heredoc; backticks inside `-m "…"` are shell-expanded.
- Targeted suite per task; one full gate (`pnpm -r test`, `pnpm -r typecheck`, `cd apps/desktop && pnpm test:e2e`) at the very end.

## Review Focus

The five conditions the spec implies but no task's happy-path test covers, most likely to bite first:

1. **A cadence that crosses local midnight.** "Every 15 minutes" created at 23:50 must next run at 00:05 the following day. An implementation that formats `23:75` gets this wrong immediately; one that adds `900_000` ms gets it right by accident and wrong after a DST shift. Pinned by the midnight test in Task 2.
2. **A tick that lands microseconds late.** The timer resolves a hair after `next_run_at` because of event-loop latency. Without slack that schedule records `missed` on every fire and never runs. Pinned by the late-tick test in Task 4.
3. **Re-enabling a schedule that has been off for days.** Its `next_run_at` is in the past, so a naive enable fires a `missed` wall immediately. The enable path must re-align instead. Pinned in Task 3.
4. **A schedule whose session was closed by hand while the run was live.** `running` is derived from the newest run's session status; if `closed` did not count as not-running, that schedule would skip every future fire forever. Pinned by the `running` test in Task 3.
5. **A turn that takes longer than the next interval.** If the tick awaited the prompt, no timer would be armed for up to the 120 s turn timeout and every other schedule would run late. The scheduler must never await a turn. Pinned by the "does not wait for the turn" test in Task 4.

```ts
/**
 * Occurrences one catch-up walk will step through before re-aligning. A one-minute schedule left
 * closed for a year is half a million `Date` constructions for a number nobody reads.
 */
export const MAX_ADVANCE_STEPS = 5_000;

const DAY_MINUTES = 1_440;

/**
 * Adds `intervalMinutes` to the local wall-clock fields of `at`, carrying whole days in the date
 * field. Reconstructing the instant from local fields is what keeps "daily at 09:00" at 09:00
 * across a DST boundary; adding `86_400_000` would land it at 08:00 or 10:00.
 */
export function advance(at: number, intervalMinutes: number): number {
  const from = new Date(at);
  const total = from.getHours() * 60 + from.getMinutes() + intervalMinutes;
  const days = Math.floor(total / DAY_MINUTES);
  const minuteOfDay = total % DAY_MINUTES;
  return new Date(
    from.getFullYear(),
    from.getMonth(),
    from.getDate() + days,
    Math.floor(minuteOfDay / 60),
    minuteOfDay % 60,
  ).getTime();
}

/** `anchorMinutes` past local midnight on the local day of `day`. */
export function anchoredOn(day: number, anchorMinutes: number): number {
  const from = new Date(day);
  return new Date(
    from.getFullYear(),
    from.getMonth(),
    from.getDate(),
    Math.floor(anchorMinutes / 60),
    anchorMinutes % 60,
  ).getTime();
}

/**
 * Walks from `from` until strictly past `after`, counting the occurrences it passed. `count` is the
 * number of runs that came due and did not happen; `next` is the first one still in the future.
 */
export function occurrencesBetween(
  from: number,
  intervalMinutes: number,
  after: number,
): { next: number; count: number } {
  if (from > after) return { next: from, count: 0 };
  let cursor = from;
  for (let count = 0; count < MAX_ADVANCE_STEPS; count += 1) {
    cursor = advance(cursor, intervalMinutes);
    if (cursor > after) return { next: cursor, count: count + 1 };
  }
  return { next: advance(after, intervalMinutes), count: MAX_ADVANCE_STEPS };
}

/** The first occurrence strictly after `after`. */
export function nextAfter(from: number, intervalMinutes: number, after: number): number {
  return occurrencesBetween(from, intervalMinutes, after).next;
}
```

```ts
import type Database from "better-sqlite3";
import { v7 as uuidv7 } from "uuid";
import {
  ErrorCodes,
  RpcFault,
  type ScheduleCreateParams,
  type ScheduleRunStatus,
  type ScheduleRunView,
  type ScheduleUpdateParams,
  type ScheduleView,
} from "@noir/protocol";
import { anchoredOn, nextAfter } from "./cadence.js";

/** The columns a fire needs; narrower than `ScheduleView` because `running` is a query, not a field. */
export interface ScheduleRecord {
  id: string;
  workspaceId: string;
  agentId: string;
  name: string;
  prompt: string;
  intervalMinutes: number;
  anchorMinutes: number;
  nextRunAt: number;
}

interface ScheduleRow {
  id: string;
  workspace_id: string;
  agent_id: string;
  name: string;
  prompt: string;
  interval_minutes: number;
  anchor_minutes: number;
  enabled: number;
  next_run_at: number;
  last_run_at: number | null;
  created_at: number;
}

interface RunRow {
  id: string;
  schedule_id: string;
  status: ScheduleRunStatus;
  due_at: number;
  started_at: number;
  session_id: string | null;
  reason: string | null;
}

const COLUMNS =
  "id, workspace_id, agent_id, name, prompt, interval_minutes, anchor_minutes, enabled, next_run_at, last_run_at, created_at";
const RUN_COLUMNS = "id, schedule_id, status, due_at, started_at, session_id, reason";

/** A session in one of these states still owns its schedule: a fire now would double up. */
const ACTIVE_SESSION: Record<string, true> = { starting: true, running: true, waiting: true };

export class ScheduleService {
  constructor(private readonly db: Database.Database) {}

  list(workspaceId?: string): ScheduleView[] {
    const rows = (
      workspaceId === undefined
        ? this.db.prepare(`SELECT ${COLUMNS} FROM schedules ORDER BY name`).all()
        : this.db.prepare(`SELECT ${COLUMNS} FROM schedules WHERE workspace_id = ? ORDER BY name`).all(workspaceId)
    ) as ScheduleRow[];
    return rows.map((row) => this.toView(row));
  }

  view(id: string): ScheduleView {
    return this.toView(this.row(id));
  }

  record(id: string): ScheduleRecord {
    const row = this.row(id);
    return {
      id: row.id,
      workspaceId: row.workspace_id,
      agentId: row.agent_id,
      name: row.name,
      prompt: row.prompt,
      intervalMinutes: row.interval_minutes,
      anchorMinutes: row.anchor_minutes,
      nextRunAt: row.next_run_at,
    };
  }

  private row(id: string): ScheduleRow {
    const row = this.db.prepare(`SELECT ${COLUMNS} FROM schedules WHERE id = ?`).get(id) as ScheduleRow | undefined;
    if (row === undefined) throw new RpcFault(ErrorCodes.notFound, "Schedule not found");
    return row;
  }

  private toView(row: ScheduleRow): ScheduleView {
    return {
      id: row.id,
      workspaceId: row.workspace_id,
      agentId: row.agent_id,
      name: row.name,
      prompt: row.prompt,
      intervalMinutes: row.interval_minutes,
      anchorMinutes: row.anchor_minutes,
      enabled: row.enabled === 1,
      nextRunAt: row.next_run_at,
      lastRunAt: row.last_run_at,
      createdAt: row.created_at,
      running: this.isRunning(row.id),
    };
  }

  /** Enabled schedules whose due instant has arrived, oldest first. */
  due(now: number): ScheduleRecord[] {
    const rows = this.db
      .prepare("SELECT id FROM schedules WHERE enabled = 1 AND next_run_at <= ? ORDER BY next_run_at")
      .all(now) as Array<{ id: string }>;
    return rows.map((row) => this.record(row.id));
  }

  /** The earliest armed instant, or undefined when nothing is enabled. */
  earliestEnabled(): number | undefined {
    const row = this.db.prepare("SELECT MIN(next_run_at) AS at FROM schedules WHERE enabled = 1").get() as
      | { at: number | null }
      | undefined;
    return row?.at ?? undefined;
  }

  create(input: ScheduleCreateParams, now: number): ScheduleView {
    const workspace = this.db.prepare("SELECT id FROM workspaces WHERE id = ?").get(input.workspaceId);
    if (workspace === undefined) throw new RpcFault(ErrorCodes.notFound, "Workspace not found");
    const agent = this.db.prepare("SELECT id FROM agents WHERE id = ?").get(input.agentId);
    if (agent === undefined) throw new RpcFault(ErrorCodes.notFound, "Agent not found");
    this.assertNameFree(input.workspaceId, input.name, null);

    const id = uuidv7();
    const nextRunAt = nextAfter(anchoredOn(now, input.anchorMinutes), input.intervalMinutes, now);
    this.db
      .prepare(
        `INSERT INTO schedules (id, workspace_id, agent_id, name, prompt, interval_minutes, anchor_minutes, enabled, next_run_at, created_at)
         VALUES (?,?,?,?,?,?,?,?,?,?)`,
      )
      .run(
        id,
        input.workspaceId,
        input.agentId,
        input.name,
        input.prompt,
        input.intervalMinutes,
        input.anchorMinutes,
        input.enabled ? 1 : 0,
        nextRunAt,
        now,
      );
    return this.view(id);
  }

  update(input: ScheduleUpdateParams, now: number): ScheduleView {
    const existing = this.row(input.id);
    const name = input.name ?? existing.name;
    if (name !== existing.name) this.assertNameFree(existing.workspace_id, name, existing.id);

    const interval = input.intervalMinutes ?? existing.interval_minutes;
    const anchor = input.anchorMinutes ?? existing.anchor_minutes;
    const enabled = input.enabled ?? existing.enabled === 1;
    const cadenceChanged = input.intervalMinutes !== undefined || input.anchorMinutes !== undefined;
    // Re-enabling or re-timing must not replay a wall of `missed` rows for the time it was off.
    const nextRunAt =
      cadenceChanged || (enabled && existing.enabled === 0)
        ? nextAfter(anchoredOn(now, anchor), interval, now)
        : existing.next_run_at;

    this.db
      .prepare(
        "UPDATE schedules SET name = ?, prompt = ?, interval_minutes = ?, anchor_minutes = ?, enabled = ?, next_run_at = ? WHERE id = ?",
      )
      .run(name, input.prompt ?? existing.prompt, interval, anchor, enabled ? 1 : 0, nextRunAt, existing.id);
    return this.view(existing.id);
  }

  remove(id: string): void {
    this.row(id);
    // Runs cascade; sessions keep their transcript and lose only the pointer, by the FK rules.
    this.db.prepare("DELETE FROM schedules WHERE id = ?").run(id);
  }

  isRunning(scheduleId: string): boolean {
    const row = this.db
      .prepare(
        `SELECT r.status AS run_status, s.status AS session_status
         FROM schedule_runs r LEFT JOIN sessions s ON s.id = r.session_id
         WHERE r.schedule_id = ? ORDER BY r.due_at DESC LIMIT 1`,
      )
      .get(scheduleId) as { run_status: ScheduleRunStatus; session_status: string | null } | undefined;
    if (row === undefined || row.run_status !== "fired") return false;
    return row.session_status !== null && ACTIVE_SESSION[row.session_status] === true;
  }

  /** A manual run's due instant: after every recorded run, so the (scheduleId, due_at) cursor stays strict. */
  nextDueAt(scheduleId: string, now: number): number {
    const row = this.db
      .prepare("SELECT MAX(due_at) AS at FROM schedule_runs WHERE schedule_id = ?")
      .get(scheduleId) as { at: number | null } | undefined;
    const newest = row?.at ?? null;
    return newest === null ? now : Math.max(now, newest + 1);
  }

  /**
   * Records a fire and advances the schedule in one transaction. Advancing first is what makes a
   * crash between the record and the session create unable to double-fire.
   */
  recordRun(input: {
    scheduleId: string;
    status: ScheduleRunStatus;
    dueAt: number;
    startedAt: number;
    reason: string | null;
    nextRunAt: number;
  }): string {
    const id = uuidv7();
    this.db.transaction(() => {
      this.db
        .prepare(
          "INSERT INTO schedule_runs (id, schedule_id, status, due_at, started_at, session_id, reason) VALUES (?,?,?,?,?,?,?)",
        )
        .run(id, input.scheduleId, input.status, input.dueAt, input.startedAt, null, input.reason);
      this.db
        .prepare("UPDATE schedules SET next_run_at = ?, last_run_at = ? WHERE id = ?")
        .run(input.nextRunAt, input.startedAt, input.scheduleId);
    })();
    return id;
  }

  /** A manual run does not touch the cadence; only `last_run_at` learns about it. */
  recordManualRun(input: { scheduleId: string; dueAt: number; startedAt: number }): string {
    const id = uuidv7();
    this.db.transaction(() => {
      this.db
        .prepare(
          "INSERT INTO schedule_runs (id, schedule_id, status, due_at, started_at, session_id, reason) VALUES (?,?,?,?,?,?,?)",
        )
        .run(id, input.scheduleId, "fired", input.dueAt, input.startedAt, null, null);
      this.db.prepare("UPDATE schedules SET last_run_at = ? WHERE id = ?").run(input.startedAt, input.scheduleId);
    })();
    return id;
  }

  attachSession(runId: string, sessionId: string): void {
    this.db.prepare("UPDATE schedule_runs SET session_id = ? WHERE id = ?").run(sessionId, runId);
  }

  failRun(runId: string, reason: string): void {
    this.db.prepare("UPDATE schedule_runs SET status = 'failed', reason = ? WHERE id = ?").run(reason, runId);
  }

  runView(runId: string): ScheduleRunView {
    const row = this.db.prepare(`SELECT ${RUN_COLUMNS} FROM schedule_runs WHERE id = ?`).get(runId) as
      | RunRow
      | undefined;
    if (row === undefined) throw new RpcFault(ErrorCodes.notFound, "Schedule run not found");
    return toRunView(row);
  }

  runs(
    scheduleId: string,
    limit: number,
    before: number | undefined,
  ): { runs: ScheduleRunView[]; nextBefore: number | null } {
    this.row(scheduleId);
    const rows = (
      before === undefined
        ? this.db
            .prepare(`SELECT ${RUN_COLUMNS} FROM schedule_runs WHERE schedule_id = ? ORDER BY due_at DESC LIMIT ?`)
            .all(scheduleId, limit)
        : this.db
            .prepare(
              `SELECT ${RUN_COLUMNS} FROM schedule_runs WHERE schedule_id = ? AND due_at < ? ORDER BY due_at DESC LIMIT ?`,
            )
            .all(scheduleId, before, limit)
    ) as RunRow[];
    // A full page means there may be more; a short one is the last by definition.
    const nextBefore = rows.length === limit ? (rows.at(-1)?.due_at ?? null) : null;
    return { runs: rows.map(toRunView), nextBefore };
  }

  private assertNameFree(workspaceId: string, name: string, ignoreId: string | null): void {
    const row = this.db
      .prepare("SELECT id FROM schedules WHERE workspace_id = ? AND name = ?")
      .get(workspaceId, name) as { id: string } | undefined;
    if (row !== undefined && row.id !== ignoreId) {
      throw new RpcFault(ErrorCodes.conflict, `A schedule named "${name}" already exists in this workspace`);
    }
  }
}

function toRunView(row: RunRow): ScheduleRunView {
  return {
    id: row.id,
    scheduleId: row.schedule_id,
    status: row.status,
    dueAt: row.due_at,
    startedAt: row.started_at,
    sessionId: row.session_id,
    reason: row.reason,
  };
}
```

```ts
import { ErrorCodes, RpcFault, type ScheduleRunStatus, type ScheduleRunView } from "@noir/protocol";
import { occurrencesBetween } from "./cadence.js";
import type { ScheduleRecord, ScheduleService } from "./schedules.js";

type TimerHandle = ReturnType<typeof setTimeout>;

/**
 * A tick that lands this far past the due instant is on time. Event-loop latency and a slow disk
 * both fit here; without the slack every fire would record itself as missed.
 */
const DEFAULT_SLACK_MS = 60_000;

export interface SchedulerOptions {
  schedules: ScheduleService;
  /** The seam that lets a test assert a fire without starting an engine. */
  createSession: (schedule: ScheduleRecord) => string;
  prompt: (sessionId: string, runId: string, text: string) => Promise<unknown>;
  now?: () => number;
  setTimer?: (fn: () => void, ms: number) => TimerHandle;
  clearTimer?: (timer: TimerHandle) => void;
  slackMs?: number;
}

/**
 * One armed timer aimed at the earliest enabled `next_run_at`. Every decision is recorded before it
 * is acted on, so a crash between the record and the session create reads as "started and died"
 * rather than firing twice.
 */
export class Scheduler {
  private timer: TimerHandle | undefined;
  private ticking = false;
  private stopped = false;

  constructor(private readonly opts: SchedulerOptions) {}

  private now(): number {
    return (this.opts.now ?? Date.now)();
  }

  start(): void {
    this.stopped = false;
    this.tick();
  }

  stop(): void {
    this.stopped = true;
    this.disarm();
  }

  /** Classifies and performs every due schedule. Synchronous: a turn is never awaited. */
  tick(): void {
    if (this.stopped || this.ticking) return;
    this.ticking = true;
    try {
      const now = this.now();
      for (const schedule of this.opts.schedules.due(now)) this.fire(schedule, now);
    } finally {
      this.ticking = false;
      this.arm();
    }
  }

  /** A manual fire. Bypasses the clock but not the overlap rule, and never moves the cadence. */
  runNow(id: string): ScheduleRunView {
    const schedule = this.opts.schedules.record(id);
    if (this.opts.schedules.isRunning(id)) {
      throw new RpcFault(ErrorCodes.conflict, "This schedule is already running");
    }
    const now = this.now();
    const runId = this.opts.schedules.recordManualRun({
      scheduleId: id,
      dueAt: this.opts.schedules.nextDueAt(id, now),
      startedAt: now,
    });
    const sessionId = this.start(schedule, runId);
    if (sessionId !== undefined) void this.opts.prompt(sessionId, runId, schedule.prompt).catch(() => undefined);
    return this.opts.schedules.runView(runId);
  }

  private fire(schedule: ScheduleRecord, now: number): void {
    const slack = this.opts.slackMs ?? DEFAULT_SLACK_MS;
    const late = now - schedule.nextRunAt;
    // Overlap first: a run that has been waiting on a person for days is still working, and
    // "skipped, still working" is truer than "missed while the app was closed".
    const status: ScheduleRunStatus = this.opts.schedules.isRunning(schedule.id)
      ? "skipped"
      : late > slack
        ? "missed"
        : "fired";
    const { next, count } = occurrencesBetween(schedule.nextRunAt, schedule.intervalMinutes, now);
    const runId = this.opts.schedules.recordRun({
      scheduleId: schedule.id,
      status,
      dueAt: schedule.nextRunAt,
      startedAt: now,
      reason: reasonFor(status, count),
      nextRunAt: next,
    });
    if (status !== "fired") return;
    const sessionId = this.start(schedule, runId);
    if (sessionId === undefined) return;
    // Deliberately detached: a turn can run for the full engine timeout, and the timer must be
    // free to arm the next schedule meanwhile.
    void this.opts.prompt(sessionId, runId, schedule.prompt).catch(() => undefined);
  }

  /** Creates the session and links it to the run; a failure marks the run and returns undefined. */
  private start(schedule: ScheduleRecord, runId: string): string | undefined {
    try {
      const sessionId = this.opts.createSession(schedule);
      this.opts.schedules.attachSession(runId, sessionId);
      return sessionId;
    } catch (error) {
      this.opts.schedules.failRun(runId, messageOf(error));
      return undefined;
    }
  }

  private disarm(): void {
    if (this.timer === undefined) return;
    (this.opts.clearTimer ?? clearTimeout)(this.timer);
    this.timer = undefined;
  }

  private arm(): void {
    this.disarm();
    if (this.stopped) return;
    const next = this.opts.schedules.earliestEnabled();
    if (next === undefined) return;
    const timer = (this.opts.setTimer ?? setTimeout)(() => this.tick(), Math.max(0, next - this.now()));
    // Nothing to wake for must not keep the process alive.
    (timer as { unref?: () => void }).unref?.();
    this.timer = timer;
  }
}

function reasonFor(status: ScheduleRunStatus, count: number): string | null {
  if (status === "missed") return `${count} run${count === 1 ? "" : "s"} missed while the app was closed`;
  if (status === "skipped") return "the previous run was still working";
  return null;
}

function messageOf(error: unknown): string {
  return error instanceof Error ? error.message : String(error);
}
```

```tsx
  const [busy, setBusy] = useState(false);

  const load = useCallback(async () => {
    const [listed, roster] = await Promise.all([
      request<{ schedules: ScheduleView[] }>("schedule.list", { workspaceId }),
      request<{ agents: AgentView[] }>("agent.list", {}),
    ]);
    setSchedules(listed.schedules);
    setAgents(roster.agents.filter((agent) => agent.archivedAt === null));
    return listed.schedules;
  }, [request, workspaceId]);

  useEffect(() => {
    void load()
      .then((listed) => setDraft(listed[0] === undefined ? EMPTY : draftOf(listed[0])))
      .catch((cause: unknown) => setError(cause instanceof Error ? cause.message : String(cause)));
  }, [load]);

  const selectedId = draft.id;
  useEffect(() => {
    if (selectedId === null) {
      setRuns([]);
      return;
    }
    void request<{ runs: ScheduleRunView[] }>("schedule.runs", { id: selectedId, limit: 20 })
      .then((result) => setRuns(result.runs))
      .catch(() => setRuns([]));
  }, [request, selectedId]);

  async function save(): Promise<void> {
    setBusy(true);
    setError(undefined);
    try {
      const { intervalMinutes, anchorMinutes } = cadenceOf(draft);
      if (draft.id === null) {
        await request("schedule.create", {
          workspaceId,
          agentId: draft.agentId === "" ? (agents[0]?.id ?? "") : draft.agentId,
          name: draft.name,
          prompt: draft.prompt,
          intervalMinutes,
          anchorMinutes,
          enabled: draft.enabled,
        });
      } else {
        await request("schedule.update", {
          id: draft.id,
          name: draft.name,
          prompt: draft.prompt,
          intervalMinutes,
          anchorMinutes,
        });
      }
      const listed = await load();
      const keep =
        draft.id === null ? listed.find((row) => row.name === draft.name) : listed.find((row) => row.id === draft.id);
      setDraft(keep === undefined ? EMPTY : draftOf(keep));
    } catch (cause) {
      setError(cause instanceof Error ? cause.message : String(cause));
    } finally {
      setBusy(false);
    }
  }

  async function toggle(schedule: ScheduleView): Promise<void> {
    try {
      await request("schedule.update", { id: schedule.id, enabled: !schedule.enabled });
      const listed = await load();
      const row = listed.find((candidate) => candidate.id === schedule.id);
      if (row !== undefined && row.id === draft.id) setDraft(draftOf(row));
    } catch (cause) {
      setError(cause instanceof Error ? cause.message : String(cause));
    }
  }

  async function runNow(schedule: ScheduleView): Promise<void> {
    try {
      const result = await request<{ run: ScheduleRunView }>("schedule.runNow", { id: schedule.id });
      if (result.run.sessionId !== null) onOpenSession(result.run.sessionId);
      const listed = await load();
      const row = listed.find((candidate) => candidate.id === schedule.id);
      if (row !== undefined) setDraft(draftOf(row));
    } catch (cause) {
      setError(cause instanceof Error ? cause.message : String(cause));
    }
  }

  return (
    <section className="automations">
      <aside role="region" aria-label="Schedules">
        <button type="button" onClick={() => setDraft({ ...EMPTY, agentId: agents[0]?.id ?? "" })}>
          New schedule
        </button>
        <ul>
          {schedules.map((schedule) => (
            <li key={schedule.id}>
              <button type="button" aria-pressed={draft.id === schedule.id} onClick={() => setDraft(draftOf(schedule))}>
                {schedule.name} · {labelFor(schedule)}
              </button>
              <span>{schedule.enabled ? "Enabled" : "Disabled"}</span>
              {schedule.running ? <span>Working</span> : null}
              <button
                type="button"
                aria-label={`${schedule.enabled ? "Disable" : "Enable"} ${schedule.name}`}
                onClick={() => void toggle(schedule)}
              >
                {schedule.enabled ? "Pause" : "Resume"}
              </button>
              <button type="button" aria-label={`Run ${schedule.name} now`} onClick={() => void runNow(schedule)}>
                Run now
              </button>
            </li>
          ))}
        </ul>
      </aside>

      <main>
        {error === undefined ? null : <p role="alert">{error}</p>}
        <form
          onSubmit={(event) => {
            event.preventDefault();
            void save();
          }}
        >
          <label>
            Name
            <input value={draft.name} onChange={(event) => setDraft({ ...draft, name: event.target.value })} />
          </label>
          <label>
            Agent
            <select
              value={draft.agentId}
              disabled={draft.id !== null}
              onChange={(event) => setDraft({ ...draft, agentId: event.target.value })}
            >
              {agents.map((agent) => (
                <option key={agent.id} value={agent.id}>
                  {agent.name}
                </option>
              ))}
            </select>
          </label>
          <label>
            Prompt
            <textarea value={draft.prompt} onChange={(event) => setDraft({ ...draft, prompt: event.target.value })} />
          </label>
          <label>
            Cadence
            <select
              value={draft.cadence}
              onChange={(event) => setDraft({ ...draft, cadence: event.target.value as Cadence })}
            >
              <option value="15">every 15 minutes</option>
              <option value="30">every 30 minutes</option>
              <option value="60">every 60 minutes</option>
              <option value="daily">daily</option>
            </select>
          </label>
          {draft.cadence === "daily" ? (
            <label>
              Time
              <input type="time" value={draft.time} onChange={(event) => setDraft({ ...draft, time: event.target.value })} />
            </label>
          ) : null}
          <button type="submit" disabled={busy}>
            Save schedule
          </button>
        </form>

        <section aria-label="Run history">
          <h3>Recent runs</h3>
          {runs.length === 0 ? <p>No runs yet.</p> : null}
          <ul>
            {runs.map((run) => (
              <li key={run.id}>
                {run.status} · {new Date(run.dueAt).toLocaleString()}
                {run.reason === null ? null : ` — ${run.reason}`}
                {run.sessionId === null ? null : (
                  <button type="button" onClick={() => onOpenSession(run.sessionId as string)}>
                    Open session
                  </button>
                )}
              </li>
            ))}
          </ul>
        </section>
      </main>
    </section>
  );
}
```

## Self-Review Notes

**Spec coverage.** §3 data model → Tasks 1 and 3. §4 scheduler (one timer, tick order, catch-up slack, overlap, failure handling) → Task 4. §5 protocol → Tasks 1 and 5. §6 panel → Task 6. §7 failure modes → one test per row across Tasks 3 and 4. §8 testing → distributed to the owning tasks, with the DST property left reviewed-not-tested as the spec states.

**Deliberately absent.** Rewriting a run's prompt from the history pane (rewriting history is not a feature), a `schedule.pauseAll` method (the per-schedule toggle is cheap and unambiguous), and any daemon or OS-level scheduler — app-open only is the approved constraint.

**Known type decisions worth restating.** `running` is a derived boolean on `ScheduleView`, never a column — a stored flag lets a crash leave a schedule permanently skipping. `ScheduleRunView.sessionId` is nullable because the run row is written before the session exists. `runNow` returns `{ run }` rather than `{ run, sessionId }` because a failed fire has no session and the caller must branch on status anyway.
