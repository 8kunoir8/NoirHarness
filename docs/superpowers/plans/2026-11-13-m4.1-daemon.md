# M4.1 Daemon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The kernel outlives the Electron window, so a scheduled run fires with no app open and an in-flight turn survives the window closing.

**Architecture:** Electron main spawns the kernel detached, attaches to it on later launches, and identifies "same build" by hashing the kernel entry. Two HTTP routes on the listener `startRpcServer` already creates carry the control plane: `GET /health` (pid + buildId, no secrets) and `POST /shutdown` (runtime token, refuses while a session is live unless forced). The tray owns the stop control; closing the window hides it.

**Tech Stack:** Node 24, TypeScript strict ESM, `ws`, `node:http`, `node:child_process`, Electron 38 (`app`, `Tray`, `Menu`, `dialog`), vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-13-m4.1-daemon-design.md`

## Global Constraints

- Node >= 24, pnpm >= 10, TypeScript strict (`noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`), ESM with `.js` import extensions, zero new runtime npm dependencies.
- One commit per task on `main`; never branch, never push, never amend.
- Service-boundary failures are `RpcFault(ErrorCodes.<code>, msg)`; HTTP routes answer JSON with an explicit status.
- Static string-keyed lookups are `Record<string, true>`, never `Set` — except where the existing code already uses a `Set` for `SessionStatus` membership (see Task 2).
- Never `: any` / `as any`; prefer `Promise.withResolvers()` over `new Promise((resolve) => …)` in new code.
- Use `edit`/`write` tools for source edits; never `sed`/`python` heredocs.
- Commit messages via `git commit -F - <<'MSG' … MSG`.
- Targeted suites per task: `pnpm -C apps/desktop exec vitest run <path>`, `cd packages/kernel && pnpm exec vitest run <path>`. One full gate at the end.
- Never log the token, a prompt, or file contents.

## Review Focus

- **Shutdown while a turn is live:** a forced stop must interrupt and record `interrupted`, never leave a session stuck in `running`. Task 2.
- **PID reuse:** `kernel.json` naming a live but unrelated pid must not count as "our daemon". Task 3.
- **Spawn failure:** a missing node binary or entry must leave a working app (child kernel + banner), not a dead window. Task 4.
- **Two launches at once:** one tray, one daemon, one spawn race winner. Task 5.
- **A closed window that never comes back:** the tray is the only way to stop the daemon, so the no-tray fallback must not strand a process. Task 5.

```ts
import { createHash } from "node:crypto";
import { readFileSync } from "node:fs";

/**
 * The identity of a kernel build: a hash of its entry file. The desktop app hashes the same file
 * before it spawns one, so "the daemon is this build" is a fact about bytes rather than a version
 * somebody forgot to bump.
 */
export function buildIdOf(file: string): string | null {
  try {
    return createHash("sha256").update(readFileSync(file)).digest("hex");
  } catch {
    return null;
  }
}
```

```ts
function sendHttp(res: ServerResponse, status: number, body: unknown): void {
```

```ts
/** The control plane: two routes, one of which can end this process. */
async function handleHttp(
  req: IncomingMessage,
  res: ServerResponse,
  opts: { token: string; buildId?: string | null; requestShutdown?: (force: boolean) => { stop: boolean; live: number }; onStopped?: () => void },
): Promise<void> {
  const url = new URL(req.url ?? "/", "http://127.0.0.1");
  if (req.method === "GET" && url.pathname === "/health") {
    sendHttp(res, 200, { status: "ok", pid: process.pid, buildId: opts.buildId ?? null });
    return;
  }
  if (req.method === "POST" && url.pathname === "/shutdown") {
    const header = req.headers.authorization ?? "";
    const provided = header.startsWith("Bearer ") ? header.slice("Bearer ".length) : "";
    if (!tokenMatches(provided, opts.token)) {
      sendHttp(res, 401, { stopped: false });
      return;
    }
    let body: unknown;
    try {
      body = await readJsonBody(req);
    } catch {
      sendHttp(res, 400, { stopped: false });
      return;
    }
    const force = typeof body === "object" && body !== null && "force" in body && body.force === true;
    const decision = opts.requestShutdown?.(force) ?? { stop: false, live: 0 };
    if (!decision.stop) {
      sendHttp(res, 409, { stopped: false, live: decision.live });
      return;
    }
    // Attach before the reply flushes: `finish` can fire on the next tick.
    res.once("finish", () => opts.onStopped?.());
    sendHttp(res, 200, { stopped: true });
    return;
  }
  sendHttp(res, 404, { error: "not found" });
}

/** Bodies here are `{force}`; anything larger is not this route's client. */
async function readJsonBody(req: IncomingMessage): Promise<unknown> {
  const chunks: Buffer[] = [];
  let size = 0;
  for await (const chunk of req) {
    const buffer = Buffer.from(chunk as Buffer);
    size += buffer.length;
    if (size > 4_096) throw new Error("body too large");
    chunks.push(buffer);
  }
  const text = Buffer.concat(chunks).toString("utf8");
  if (text === "") return {};
  return JSON.parse(text);
}
```

```ts
/**
 * True only when the endpoint answers `/health` as the pid the caller expects. The runtime file's
 * token is deliberately not sent: a health reply carries no secret, and a process that can bind this
 * port on this machine can already read the file.
 */
async function probeHealth(info: RuntimeInfo, timeoutMs: number): Promise<boolean> {
  try {
    const res = await fetch(`http://127.0.0.1:${info.port}/health`, { signal: AbortSignal.timeout(timeoutMs) });
    if (!res.ok) return false;
    const body: unknown = await res.json();
    return typeof body === "object" && body !== null && "status" in body && body.status === "ok" && "pid" in body && body.pid === info.pid;
  } catch {
    return false;
  }
}
```

```ts
import { spawn, type SpawnOptions } from "node:child_process";
import { closeSync, mkdirSync, openSync, readFileSync, renameSync, statSync, unlinkSync } from "node:fs";
import { join } from "node:path";

export interface HostTarget {
  dataDir: string;
  kernelEntry: string;
  nodeBin: string;
}

export interface HostedKernel {
  port: number;
  token: string;
  pid: number;
  /** False when the kernel had to be spawned as a plain child of the app. */
  daemon: boolean;
  /** False when the app talks to a different build than the one it would spawn. */
  buildMatches: boolean;
}

interface HealthInfo {
  status: string;
  pid: number;
  buildId: string | null;
}

interface RuntimeFile {
  pid: number;
  port: number;
  token: string;
}

export interface HostDeps {
  buildId?: (file: string) => string | null;
  probeHealth?: (port: number, timeoutMs: number) => Promise<HealthInfo | null>;
  requestShutdown?: (port: number, token: string, force: boolean) => Promise<{ status: number; body: { live?: number } }>;
  isAlive?: (pid: number) => boolean;
  waitRuntime?: (file: string, timeoutMs: number) => Promise<RuntimeFile>;
  spawnProcess?: (bin: string, args: string[], opts: SpawnOptions) => { unref(): void };
  killPid?: (pid: number) => void;
  sleep?: (ms: number) => Promise<void>;
  /** Asked only when a replacement would kill work; resolves what the user chose. */
  promptBusy?: (live: number) => Promise<"stop" | "keep">;
}

type ResolvedDeps = Required<HostDeps>;

const PROBE_TIMEOUT_MS = 750;
const EXIT_TIMEOUT_MS = 5_000;
const START_TIMEOUT_MS = 20_000;
const LOG_LIMIT_BYTES = 2_000_000;

export function runtimeFilePath(dataDir: string): string {
  return join(dataDir, "runtime", "kernel.json");
}

function readRuntimeFile(file: string): RuntimeFile | null {
  try {
    const parsed: unknown = JSON.parse(readFileSync(file, "utf8"));
    if (typeof parsed !== "object" || parsed === null) return null;
    const candidate = parsed as { pid?: unknown; port?: unknown; token?: unknown };
    if (typeof candidate.pid !== "number" || typeof candidate.port !== "number" || typeof candidate.token !== "string") return null;
    return { pid: candidate.pid, port: candidate.port, token: candidate.token };
  } catch {
    return null;
  }
}

function isProcessAlive(pid: number): boolean {
  try {
    process.kill(pid, 0);
    return true;
  } catch (error) {
    return typeof error === "object" && error !== null && "code" in error && error.code === "EPERM";
  }
}

/** Append descriptor for `<dataDir>/logs/kernel.log`; a 2 MB file is rotated first. */
export function openLog(dataDir: string): number {
  const dir = join(dataDir, "logs");
  mkdirSync(dir, { recursive: true });
  const file = join(dir, "kernel.log");
  try {
    if (statSync(file).size > LOG_LIMIT_BYTES) {
      try {
        unlinkSync(join(dir, "kernel.1.log"));
      } catch {
        // No previous rotation.
      }
      renameSync(file, join(dir, "kernel.1.log"));
    }
  } catch {
    // First run: nothing to rotate.
  }
  return openSync(file, "a");
}

async function probeHealth(port: number, timeoutMs: number): Promise<HealthInfo | null> {
  try {
    const res = await fetch(`http://127.0.0.1:${port}/health`, { signal: AbortSignal.timeout(timeoutMs) });
    if (!res.ok) return null;
    const body: unknown = await res.json();
    if (typeof body !== "object" || body === null) return null;
    const candidate = body as { status?: unknown; pid?: unknown; buildId?: unknown };
    if (candidate.status !== "ok" || typeof candidate.pid !== "number") return null;
    return { status: "ok", pid: candidate.pid, buildId: typeof candidate.buildId === "string" ? candidate.buildId : null };
  } catch {
    return null;
  }
}

async function requestShutdown(port: number, token: string, force: boolean): Promise<{ status: number; body: { live?: number } }> {
  const res = await fetch(`http://127.0.0.1:${port}/shutdown`, {
    method: "POST",
    headers: { authorization: `Bearer ${token}`, "content-type": "application/json", connection: "close" },
    body: JSON.stringify({ force }),
    signal: AbortSignal.timeout(EXIT_TIMEOUT_MS),
  });
  const body = await res.json().catch(() => ({}));
  return { status: res.status, body: typeof body === "object" && body !== null ? (body as { live?: number }) : {} };
}

async function waitRuntime(file: string, timeoutMs: number): Promise<RuntimeFile> {
  const deadline = Date.now() + timeoutMs;
  for (;;) {
    const info = readRuntimeFile(file);
    if (info !== null && isProcessAlive(info.pid)) return info;
    if (Date.now() > deadline) throw new Error("Kernel did not start");
    await new Promise<void>((resolve) => setTimeout(resolve, 100));
  }
}

async function waitGone(pid: number, sleep: (ms: number) => Promise<void>): Promise<void> {
  const deadline = Date.now() + EXIT_TIMEOUT_MS;
  while (Date.now() < deadline) {
    if (!isProcessAlive(pid)) return;
    await sleep(50);
  }
}

export async function hostKernel(target: HostTarget, overrides: HostDeps = {}): Promise<HostedKernel> {
  const deps: ResolvedDeps = {
    buildId: buildIdOfFile,
    probeHealth,
    requestShutdown,
    isAlive: isProcessAlive,
    waitRuntime,
    spawnProcess: (bin, args, opts) => spawn(bin, args, opts),
    killPid: (pid) => void process.kill(pid, "SIGTERM"),
    sleep: (ms) => new Promise<void>((resolve) => setTimeout(resolve, ms)),
    promptBusy: async () => "keep",
    ...overrides,
  };
  const file = runtimeFilePath(target.dataDir);
  const wanted = deps.buildId(target.kernelEntry);

  const current = readRuntimeFile(file);
  if (current !== null && deps.isAlive(current.pid)) {
    const health = await deps.probeHealth(current.port, PROBE_TIMEOUT_MS);
    if (health !== null && health.pid === current.pid) {
      if (health.buildId === wanted) return { port: current.port, token: current.token, pid: current.pid, daemon: true, buildMatches: true };
      const outcome = await deps.requestShutdown(current.port, current.token, false);
      if (outcome.status === 200) {
        await waitGone(current.pid, deps.sleep);
      } else if (outcome.status === 409) {
        if ((await deps.promptBusy(outcome.body.live ?? 0)) === "keep") {
          return { port: current.port, token: current.token, pid: current.pid, daemon: true, buildMatches: false };
        }
        await deps.requestShutdown(current.port, current.token, true);
        await waitGone(current.pid, deps.sleep);
      } else {
        // A daemon from before the control plane existed: signal it and wait.
        deps.killPid(current.pid);
        await waitGone(current.pid, deps.sleep);
      }
    }
  }

  return spawnDetached(target, deps);
}

async function spawnDetached(target: HostTarget, deps: ResolvedDeps): Promise<HostedKernel> {
  const file = runtimeFilePath(target.dataDir);
  const env = { ...process.env, ELECTRON_RUN_AS_NODE: "1", NOIR_DATA_DIR: target.dataDir };
  const spawnOnce = (detached: boolean): void => {
    const fd = openLog(target.dataDir);
    try {
      deps.spawnProcess(target.nodeBin, [target.kernelEntry], {
        detached,
        windowsHide: true,
        stdio: ["ignore", fd, fd],
        env,
      }).unref();
    } finally {
      closeSync(fd);
    }
  };
  let daemon = true;
  try {
    spawnOnce(true);
  } catch {
    daemon = false;
    spawnOnce(false);
  }
  const info = await deps.waitRuntime(file, START_TIMEOUT_MS);
  return { port: info.port, token: info.token, pid: info.pid, daemon, buildMatches: true };
}

function buildIdOfFile(file: string): string | null {
  // Re-declared rather than imported: only the kernel ships a `buildIdOf`, and main must not pull
  // the kernel package into the Electron bundle for one hash.
  try {
    return createHash("sha256").update(readFileSync(file)).digest("hex");
  } catch {
    return null;
  }
}
```

```ts
export interface TrayActions {
  show(): void;
  stopDaemon(): void;
  quit(): void;
  quitAndStop(): void;

/** Always a full sentence: the menu must not change height when the count does. */
export function armedLabel(count: number): string {
  if (count === 0) return "No automations armed";
  return count === 1 ? "1 automation armed" : `${count} automations armed`;
}

/**
 * `Stop daemon` and `Quit` are separate rows on purpose: quitting the window is the common action
 * and must not silently kill a running turn, and stopping the daemon must not be reachable by

export function trayMenu(armed: number, actions: TrayActions): MenuItemConstructorOptions[] {
  return [
    { label: "Show NoirHarness", click: () => actions.show() },
    { label: armedLabel(armed), enabled: false },
    { type: "separator" },
    { label: "Stop daemon", click: () => actions.stopDaemon() },
    { type: "separator" },
    { label: "Quit", click: () => actions.quit() },
    { label: "Quit and stop daemon", click: () => actions.quitAndStop() },
  ];
}
```

```ts
/** Asks the daemon to stop through its own control plane, then waits for the pid to go. */
export async function stopKernel(dataDir: string): Promise<void> {
  const runtimeFile = join(dataDir, "runtime", "kernel.json");
  if (!existsSync(runtimeFile)) return;
  const pid = runtimePid(dataDir);
  const signal = (): void => {
    if (pid !== undefined) process.kill(pid, "SIGTERM");
  };
  try {
    const runtime = readKernelRuntime(dataDir);
    const res = await fetch(`http://127.0.0.1:${String(runtime.port)}/shutdown`, {
      method: "POST",
      headers: { authorization: `Bearer ${runtime.token}`, "content-type": "application/json", connection: "close" },
      body: JSON.stringify({ force: true }),
      signal: AbortSignal.timeout(15_000),
    });
    // A 404 means a build that predates the control plane; anything not 2xx falls back to a signal.
    if (!res.ok) signal();
  } catch {
    // Already gone, or never reachable: the signal is the only remaining lever.
    signal();
  }
  await waitForKernelExit(dataDir);
}
```
