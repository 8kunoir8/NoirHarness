# M1.3 — Editor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The workspace becomes editable: file tree, Monaco editor that saves through the kernel, git-backed diff stats, a diff tab, and line annotations attached to a diff reference.

**Architecture:** The kernel stays the only filesystem and git authority. New `fs.*` RPCs are workspace-scoped — the renderer sends a `workspaceId` and a relative POSIX path, never an absolute root — and new `git.*` RPCs spawn `git` with the workspace root as cwd. The renderer gains a typed tab model (`chat | editor | diff`), a lazy-loaded Monaco editor, a lazily expanded file tree, and a token-styled unified diff view. Diff stats come from `git.status`, not from engine events, so the exit criterion ("editing a file updates diff stats and opens a diff tab") is provable without a live model.

**Tech Stack:** TypeScript 5 strict, zod, better-sqlite3, React 19, Vite 6, Monaco (`monaco-editor`), Vitest, Playwright (Electron).

**Spec:** `docs/superpowers/specs/2026-11-09-noirharness-design.md` §8.1, §8.3, §13 (M1.3 row).

## Global Constraints

- Node 24+, pnpm 10+, Windows-first. Never `python`/`sed` for edits; use the editor tools.
- TS strict with `noUncheckedIndexedAccess` and `exactOptionalPropertyTypes`; no `any` in renderer code.
- Renderer is a pure consumer: WebSocket JSON-RPC + events only; no Node APIs, no secrets.
- Events stay append-only with a gap-free per-session `seq`; the reducer stays replay-safe.
- Every new RPC is validated with a zod schema in `packages/protocol/src/rpc.ts` before it reaches a service.
- Workspace is the write boundary: `fs.write` outside the workspace root must be impossible, including `..` and symlink escapes.
- Monaco is bundled offline: no CDN, no network fetch at runtime.
- Playwright `getByLabel` is case-insensitive — always pass `{ exact: true }`.
- Desktop unit tests have no jest-dom: assert with `.textContent` / `.toBeTruthy()`.
- Existing e2e contract names must keep working: regions `Providers`/`Models`/`Projects`/`Sessions`/`Chat`, labels `Prompt`, `Send`, `Interrupt`, testids `kernel-status`, `session-status`, `message-assistant`, `tool-card`, `permission-card`.

## Review Focus

- **Path containment:** `../x`, absolute Windows paths (`C:\\x`), UNC paths, and a symlink inside the workspace pointing outside must all be rejected by `fs.*` and `git.*`; the kernel must resolve and compare real paths, not strings.
- **File size and encoding:** opening a 40 MB log or a PNG must not freeze the kernel or the renderer; `fs.read` returns a truncation flag and `fs.read`/`fs.write` refuse non-UTF-8 content with a clear error.
- **No git, no repo:** a workspace whose directory is not a git repository (or a machine without `git`) must show zero diff stats and still allow editing and saving, never an error wall.
- **Unsaved edits:** closing an editor tab, switching tabs, or saving over a file that changed on disk must not silently discard work — the tab stays and the conflict is reported.
- **Diff staleness:** annotations belong to a specific diff; after the file changes the old notes must not appear lined up with unrelated new lines.

```ts
// packages/kernel/src/fsPaths.ts
import { realpathSync } from "node:fs";
import { dirname, isAbsolute, join, relative } from "node:path";
import { ErrorCodes, RpcFault } from "@noir/protocol";

/** Wire paths are relative and `/`-separated, whatever the host separator is. */
export function relativePath(value: string): string {
  if (isAbsolute(value) || /^[A-Za-z]:/.test(value) || value.startsWith("\\\\")) {
    throw new RpcFault(ErrorCodes.invalidParams, `Path must be relative: ${value}`);
  }
  const segments = value.split("/").filter((segment) => segment !== "" && segment !== ".");
  if (segments.includes("..")) {
    throw new RpcFault(ErrorCodes.invalidParams, `Path must not contain "..": ${value}`);
  }
  return segments.join("/");
}

/** Real path of the deepest existing ancestor, so a not-yet-created file is still checked. */
function realAncestor(path: string): string {
  let current = path;
  for (;;) {
    try {
      return realpathSync(current);
    } catch {
      const parent = dirname(current);
      if (parent === current) return current;
      current = parent;
    }
  }
}

function assertInside(root: string, target: string): void {
  const rel = relative(root, target);
  if (rel === "") return;
  if (rel.startsWith("..") || isAbsolute(rel)) {
    throw new RpcFault(ErrorCodes.invalidParams, `Path escapes the workspace: ${target}`);
  }
}

export function resolveInsideRoot(root: string, value: string): string {
  const rel = relativePath(value);
  const absolute = rel === "" ? root : join(root, ...rel.split("/"));
  if (rel !== "") assertInside(realAncestor(root), realAncestor(absolute));
  return absolute;
}
```

```ts
// packages/kernel/src/fsService.ts
import { readFile, readdir, stat, writeFile } from "node:fs/promises";
import { dirname, join } from "node:path";
import { ErrorCodes, RpcFault } from "@noir/protocol";
import { relativePath, resolveInsideRoot } from "./fsPaths.js";

export const MAX_LIST_ENTRIES = 2_000;
export const MAX_READ_BYTES = 2 * 1024 * 1024;
export const MAX_FIND_FILES = 5_000;
const SKIP_DIRS = new Set([".git", "node_modules", ".noir"]);

export interface FsEntryView {
  name: string;
  path: string;
  kind: "file" | "dir";
  size: number;
}

function joinRel(parent: string, name: string): string {
  return parent === "" ? name : `${parent}/${name}`;
}

export async function listDirectory(
  root: string,
  value: string,
): Promise<{ entries: FsEntryView[]; truncated: boolean }> {
  const rel = relativePath(value);
  const absolute = resolveInsideRoot(root, rel);
  const dirents = await readdir(absolute, { withFileTypes: true }).catch(() => {
    throw new RpcFault(ErrorCodes.notFound, `Directory not found: ${rel}`);
  });
  const entries: FsEntryView[] = [];
  for (const dirent of dirents) {
    if (dirent.name === ".git") continue;
    const path = joinRel(rel, dirent.name);
    const kind = dirent.isDirectory() ? "dir" : "file";
    let size = 0;
    if (kind === "file") size = (await stat(join(absolute, dirent.name))).size;
    entries.push({ name: dirent.name, path, kind, size });
  }
  entries.sort((a, b) => (a.kind === b.kind ? a.name.localeCompare(b.name) : a.kind === "dir" ? -1 : 1));
  return { entries: entries.slice(0, MAX_LIST_ENTRIES), truncated: entries.length > MAX_LIST_ENTRIES };
}

export async function readFileText(
  root: string,
  value: string,
): Promise<{ content: string; size: number; mtimeMs: number; truncated: boolean }> {
  const rel = relativePath(value);
  const absolute = resolveInsideRoot(root, rel);
  const info = await stat(absolute).catch(() => {
    throw new RpcFault(ErrorCodes.notFound, `File not found: ${rel}`);
  });
  if (!info.isFile()) throw new RpcFault(ErrorCodes.invalidParams, `Not a file: ${rel}`);
  const buffer = await readFile(absolute);
  const slice = buffer.subarray(0, MAX_READ_BYTES);
  if (slice.includes(0)) throw new RpcFault(ErrorCodes.invalidParams, `Not a text file: ${rel}`);
  const truncated = buffer.length > MAX_READ_BYTES;
  return {
    content: decodeUtf8(slice, truncated),
    size: buffer.length,
    mtimeMs: Math.floor(info.mtimeMs),
    truncated,
  };
}

/** Strict UTF-8; a truncated read may end mid-codepoint, so drop at most three tail bytes first. */
function decodeUtf8(buffer: Buffer, truncated: boolean): string {
  const decoder = new TextDecoder("utf-8", { fatal: true });
  for (let drop = 0; drop <= (truncated ? 3 : 0); drop += 1) {
    try {
      return decoder.decode(buffer.subarray(0, buffer.length - drop));
    } catch {
      if (drop === (truncated ? 3 : 0)) break;
    }
  }
  throw new RpcFault(ErrorCodes.invalidParams, "Not a UTF-8 text file");
}

export async function writeFileText(
  root: string,
  value: string,
  content: string,
  expectedMtimeMs?: number,
): Promise<{ mtimeMs: number }> {
  const rel = relativePath(value);
  if (rel === "") throw new RpcFault(ErrorCodes.invalidParams, "A file path is required");
  const absolute = resolveInsideRoot(root, rel);
  const parent = dirname(absolute);
  await stat(parent).catch(() => {
    throw new RpcFault(ErrorCodes.notFound, `Directory not found: ${rel.split("/").slice(0, -1).join("/")}`);
  });
  if (expectedMtimeMs !== undefined) {
    const current = await stat(absolute).catch(() => undefined);
    if (current !== undefined && Math.floor(current.mtimeMs) !== expectedMtimeMs) {
      throw new RpcFault(ErrorCodes.conflict, `${rel} changed on disk`);
    }
  }
  await writeFile(absolute, content, "utf8");
  return { mtimeMs: Math.floor((await stat(absolute)).mtimeMs) };
}

/** Every file under the root, for the quick-open picker; git and dependency dirs are skipped. */
export async function findFiles(root: string): Promise<{ files: string[]; truncated: boolean }> {
  const files: string[] = [];
  const walk = async (rel: string): Promise<void> => {
    if (files.length >= MAX_FIND_FILES) return;
    const dirents = await readdir(resolveInsideRoot(root, rel), { withFileTypes: true }).catch(() => []);
    for (const dirent of dirents) {
      if (files.length >= MAX_FIND_FILES) return;
      if (dirent.isDirectory() && SKIP_DIRS.has(dirent.name)) continue;
      const path = joinRel(rel, dirent.name);
      if (dirent.isDirectory()) await walk(path);
      else if (dirent.isFile()) files.push(path);
    }
  };
  await walk("");
  return { files: files.sort(), truncated: files.length >= MAX_FIND_FILES };
}
```

```ts
async function call(kernel: Kernel, method: string, params?: unknown): Promise<any> {
  const ws = new WebSocket(`ws://127.0.0.1:${kernel.port}/?token=${kernel.token}`);
  await once(ws, "open");
  const reply = once(ws, "message");
  ws.send(JSON.stringify({ jsonrpc: "2.0", id: 1, method, params }));
  const [data] = await reply;
  ws.close();
  return JSON.parse(String(data));
}

function git(root: string, ...args: string[]): void {
  execFileSync("git", args, { cwd: root, stdio: "ignore" });
}

async function setupRepo(): Promise<{ kernel: Kernel; workspaceId: string; root: string }> {
  const root = tempDir();
  writeFileSync(join(root, "a.txt"), "one\n");
  writeFileSync(join(root, "b.txt"), "gone\n");

  git(root, "config", "user.email", "t@example.com");
  git(root, "config", "user.name", "T");

  const project = await call(kernel, "project.add", { path: root });
  const workspace = await call(kernel, "workspace.create", { projectId: project.result.id });

}
```

```ts
// packages/kernel/src/gitService.ts
import { execFile } from "node:child_process";
import { promisify } from "node:util";
import { readFile, stat } from "node:fs/promises";
import { ErrorCodes, RpcFault } from "@noir/protocol";
import { relativePath, resolveInsideRoot } from "./fsPaths.js";

const run = promisify(execFile);
const GIT = process.env.NOIR_GIT_COMMAND ?? "git";
const TIMEOUT_MS = 5_000;

export interface GitFileStatusView {
  path: string;
  change: "created" | "modified" | "deleted";
  add: number;
  del: number;
}

export interface GitStatusView {
  isRepo: boolean;
  branch: string | null;
  files: GitFileStatusView[];
}

async function git(root: string, args: string[]): Promise<string> {
  const result = await run(GIT, ["-c", "core.quotepath=false", ...args], {
    cwd: root,
    timeout: TIMEOUT_MS,
    windowsHide: true,
    maxBuffer: 16 * 1024 * 1024,
    encoding: "utf8",
  }).catch((error: unknown) => {
    throw new RpcFault(ErrorCodes.internal, error instanceof Error ? error.message : "git failed");
  });
  return result.stdout;
}

async function isRepo(root: string): Promise<boolean> {
  try {
    return (await git(root, ["rev-parse", "--is-inside-work-tree"])).trim() === "true";
  } catch {
    return false;
  }
}

export async function gitStatus(root: string): Promise<GitStatusView> {
  if (!(await isRepo(root))) return { isRepo: false, branch: null, files: [] };
  const branch = await git(root, ["rev-parse", "--abbrev-ref", "HEAD"]).catch(() => "");
  const porcelain = await git(root, ["status", "--porcelain=v1", "-z", "--untracked-files=all"]);
  // A repository with no commit yet has no HEAD to diff against; untracked files still report.
  const numstat = await git(root, ["diff", "--numstat", "-z", "HEAD", "--"]).catch(() => "");
  const counts = new Map<string, { add: number; del: number }>();
  for (const record of numstat.split("\0")) {
    const [add, del, path] = record.split("\t");
    // Rename records carry an empty path: their counts arrive under the destination path instead.
    if (path === undefined || path === "" || add === undefined || del === undefined) continue;
    counts.set(path, { add: Number(add) || 0, del: Number(del) || 0 });
  }
  const records = porcelain.split("\0");
  const files: GitFileStatusView[] = [];
  for (let index = 0; index < records.length; index += 1) {
    const record = records[index] ?? "";
    if (record.length < 4) continue;
    const code = record.slice(0, 2);
    const path = record.slice(3);
    // `-z` renames emit the destination first and the source as the next record; skip the source.
    if (code.includes("R") || code.includes("C")) {
      index += 1;
      continue;
    }
    const change = code === "??" ? "created" : code.includes("D") ? "deleted" : code.includes("A") ? "created" : "modified";
    const counted = counts.get(path) ?? { add: 0, del: 0 };
    const createdLines =
      change === "created"
        ? (await readFile(resolveInsideRoot(root, path), "utf8").catch(() => "")).split("\n").filter((line) => line !== "").length
        : 0;
    files.push({
      path,
      change,
      add: change === "deleted" ? 0 : createdLines > 0 ? createdLines : counted.add,
      del: change === "deleted" ? counted.del || 1 : counted.del,
    });
  }
  files.sort((a, b) => a.path.localeCompare(b.path));
  return { isRepo: true, branch: branch.trim() === "" ? null : branch.trim(), files };
}

export async function gitDiff(root: string, value: string): Promise<string> {
  if (!(await isRepo(root))) return "";
  const path = relativePath(value);
  const absolute = resolveInsideRoot(root, path);
  const tracked = await git(root, ["ls-files", "--error-unmatch", "--", path]).then(
    () => true,
    () => false,
  );
  if (tracked) return git(root, ["diff", "--no-color", "HEAD", "--", path]);
  const exists = await stat(absolute).then(
    (info) => info.isFile(),
    () => false,
  );
  if (!exists) return "";
  const lines = (await readFile(absolute, "utf8")).split("\n");
  if (lines.at(-1) === "") lines.pop();
  const body = lines.map((line) => `+${line}`).join("\n");
  return ["--- /dev/null", `+++ b/${path}`, `@@ -0,0 +1,${lines.length} @@`, body, ""].join("\n");
}
```

```ts
// apps/desktop/src/renderer/tabs.ts
export type Tab =
  | { id: string; kind: "chat"; sessionId: string }
  | { id: string; kind: "editor"; path: string }
  | { id: string; kind: "diff"; path: string };

export interface TabsState {
  tabs: Tab[];
  active: string | undefined;
}

export const TABS_KEY = "noir.tabs.v2";

export function chatTab(sessionId: string): Tab {
  return { id: `chat:${sessionId}`, kind: "chat", sessionId };
}
export function editorTab(path: string): Tab {
  return { id: `editor:${path}`, kind: "editor", path };
}
export function diffTab(path: string): Tab {
  return { id: `diff:${path}`, kind: "diff", path };
}

export function openTab(state: TabsState, tab: Tab): TabsState {
  if (state.tabs.some((candidate) => candidate.id === tab.id)) return { tabs: state.tabs, active: tab.id };
  return { tabs: [...state.tabs, tab], active: tab.id };
}

export function activateTab(state: TabsState, id: string): TabsState {
  if (!state.tabs.some((tab) => tab.id === id) || state.active === id) return state;
  return { tabs: state.tabs, active: id };
}

export function closeTab(state: TabsState, id: string): TabsState {
  const index = state.tabs.findIndex((tab) => tab.id === id);
  if (index === -1) return state;
  const tabs = state.tabs.filter((tab) => tab.id !== id);
  if (state.active !== id) return { tabs, active: state.active };
  const neighbour = tabs[Math.min(index, tabs.length - 1)];
  return { tabs, active: neighbour?.id };
}

function isTab(value: unknown): value is Tab {
  if (typeof value !== "object" || value === null) return false;
  const candidate = value as Record<string, unknown>;
  if (candidate.kind === "chat") return typeof candidate.sessionId === "string" && candidate.sessionId !== "";
  if (candidate.kind === "editor" || candidate.kind === "diff") {
    return typeof candidate.path === "string" && candidate.path !== "";
  }
  return false;
}

function normalize(tab: Tab): Tab {
  if (tab.kind === "chat") return chatTab(tab.sessionId);
  return tab.kind === "editor" ? editorTab(tab.path) : diffTab(tab.path);
}

/** Accepts the v2 shape and migrates the v1 chat-id list; anything unrecognized becomes empty. */
export function loadTabs(raw: unknown): TabsState {
  if (typeof raw !== "object" || raw === null) return { tabs: [], active: undefined };
  const record = raw as { tabs?: unknown; open?: unknown; active?: unknown };
  const source = Array.isArray(record.tabs) ? record.tabs.filter(isTab) : [];
  const migrated = Array.isArray(record.open)
    ? record.open.filter((id): id is string => typeof id === "string" && id !== "").map(chatTab)
    : [];
  const tabs = (source.length > 0 ? source : migrated).map(normalize);
  const requested = typeof record.active === "string" ? record.active : undefined;
  const active =
    requested !== undefined && tabs.some((tab) => tab.id === requested)
      ? requested
      : requested !== undefined && tabs.some((tab) => tab.id === `chat:${requested}`)
        ? `chat:${requested}`
        : tabs[0]?.id;
  return { tabs, active };
}
```

```tsx
// apps/desktop/src/renderer/FileTree.tsx
import { useEffect, useState } from "react";
import type { RequestFn } from "./api.js";

interface Entry {
  name: string;
  path: string;
  kind: "file" | "dir";
  size: number;
}

interface Listing {
  entries: Entry[];
  truncated: boolean;
}

export interface FileTreeProps {
  request: RequestFn;
  workspaceId: string;
  activePath?: string | undefined;
  onOpenFile: (path: string) => void;
}

/** Lazily expanded tree over `fs.list`; expansions and listings are cached for the mount. */
export function FileTree({ request, workspaceId, activePath, onOpenFile }: FileTreeProps) {
  const [listings, setListings] = useState<Record<string, Listing>>({});
  const [expanded, setExpanded] = useState<ReadonlySet<string>>(new Set());
  const [error, setError] = useState<string | undefined>(undefined);

  const load = (path: string): void => {
    if (listings[path] !== undefined) return;
    setListings((current) => ({ ...current, [path]: { entries: [], truncated: false } }));
    void request<Listing>("fs.list", { workspaceId, path }).then(
      (listing) => setListings((current) => ({ ...current, [path]: listing })),
      (cause: unknown) => {
        setListings((current) => {
          const next = { ...current };
          delete next[path];
          return next;
        });
        setError(cause instanceof Error ? cause.message : "Could not read the directory");
      },
    );
  };

  useEffect(() => {
    setListings({});
    setExpanded(new Set());
    setError(undefined);
    load("");
    // eslint-disable-next-line react-hooks/exhaustive-deps -- reload only when the workspace changes
  }, [workspaceId]);

  const toggle = (path: string): void => {
    setExpanded((current) => {
      const next = new Set(current);
      if (next.has(path)) next.delete(path);
      else {
        next.add(path);
        load(path);
      }
      return next;
    });
  };

  const rows: Array<{ entry: Entry; depth: number }> = [];
  const walk = (path: string, depth: number): void => {
    for (const entry of listings[path]?.entries ?? []) {
      rows.push({ entry, depth });
      if (entry.kind === "dir" && expanded.has(entry.path)) walk(entry.path, depth + 1);
    }
  };
  walk("", 0);

  return (
    <section aria-label="Files" className="file-tree">
      <h3>Files</h3>
      {error === undefined ? null : <p role="alert">{error}</p>}
      <ul role="tree" aria-label="Workspace files">
        {rows.map(({ entry, depth }) => (
          <li
            key={entry.path}
            role="treeitem"
            aria-selected={entry.path === activePath}
            aria-expanded={entry.kind === "dir" ? expanded.has(entry.path) : undefined}
            tabIndex={0}
            data-depth={depth}
            onClick={() => (entry.kind === "dir" ? toggle(entry.path) : onOpenFile(entry.path))}
            onKeyDown={(event) => {
              if (event.key !== "Enter" && event.key !== " ") return;
              event.preventDefault();
              if (entry.kind === "dir") toggle(entry.path);
              else onOpenFile(entry.path);
            }}
          >
            <span className="file-kind" aria-hidden="true">
              {entry.kind === "dir" ? (expanded.has(entry.path) ? "▾" : "▸") : "·"}
            </span>
            {entry.name}
          </li>
        ))}
      </ul>
    </section>
  );
}
```

```tsx
import { useEffect, useRef, useState } from "react";
import type * as Monaco from "monaco-editor";
import { editorThemeFor, languageFor, loadMonaco } from "./monaco.js";

  path: string;
  value: string;
  theme: "paper" | "ink";
  onChange: (value: string) => void;

/** Mounts one Monaco model per path; the parent owns the text and the save action. */
export function MonacoEditor({ path, value, theme, onChange }: MonacoEditorProps) {
  const host = useRef<HTMLDivElement | null>(null);
  const editor = useRef<Monaco.editor.IStandaloneCodeEditor | undefined>(undefined);
  const latest = useRef(onChange);
  const [failure, setFailure] = useState<string | undefined>(undefined);
  latest.current = onChange;

  useEffect(() => {
    const element = host.current;
    if (element === null) return;
    let disposed = false;
    let subscription: Monaco.IDisposable | undefined;
    void loadMonaco().then(
      (monaco) => {
        if (disposed) return;
        const instance = monaco.editor.create(element, {
          value,
          language: languageFor(path),
          theme: editorThemeFor(theme),
          automaticLayout: true,
          minimap: { enabled: false },
          fontSize: 13,
          scrollBeyondLastLine: false,
        });
        subscription = instance.onDidChangeModelContent(() => latest.current(instance.getValue()));
        editor.current = instance;
      },
      (error: unknown) => setFailure(error instanceof Error ? error.message : "Editor failed to load"),
    );
    return () => {
      disposed = true;
      subscription?.dispose();
      editor.current?.dispose();
      editor.current = undefined;
    };
  }, [path]);

  useEffect(() => {
    editor.current?.updateOptions({ theme: editorThemeFor(theme) });
  }, [theme]);

  // Adopt an externally loaded document (a fresh read) without fighting the typist.
  useEffect(() => {
    const instance = editor.current;
    if (instance === undefined) return;
    const model = instance.getModel();
    if (model !== null && model.getValue() !== value && !instance.hasTextFocus()) model.setValue(value);
  }, [value]);

  return (
    <div className="editor-host">
      {failure === undefined ? null : <p role="alert">{failure}</p>}
      <div data-testid="monaco-host" ref={host} className="editor-surface" />
    </div>
  );
}
```

```ts
// packages/kernel/src/annotations.ts
import { createHash } from "node:crypto";
import type Database from "better-sqlite3";
import { v7 as uuidv7 } from "uuid";
import { ErrorCodes, RpcFault } from "@noir/protocol";
import { gitDiff } from "./gitService.js";

export interface AnnotationRow {
  id: string;
  line: number;
  note: string;
  createdAt: number;
  stale: boolean;
}

async function hashFor(root: string, path: string): Promise<string> {
  return createHash("sha256").update(await gitDiff(root, path)).digest("hex");
}

export async function listAnnotations(
  db: Database.Database,
  root: string,
  workspaceId: string,
  path: string,
): Promise<{ diffHash: string; annotations: AnnotationRow[] }> {
  const diffHash = await hashFor(root, path);
  const rows = db
    .prepare("SELECT id, line, note, diff_hash, created_at FROM annotations WHERE workspace_id = ? AND path = ? ORDER BY line, created_at")
    .all(workspaceId, path) as Array<Record<string, unknown>>;
  return {
    diffHash,
    annotations: rows.map((row) => ({
      id: row.id as string,
      line: row.line as number,
      note: row.note as string,
      createdAt: row.created_at as number,
      stale: (row.diff_hash as string) !== diffHash,
    })),
  };
}

export async function addAnnotation(
  db: Database.Database,
  root: string,
  params: { workspaceId: string; path: string; line: number; note: string },
): Promise<AnnotationRow> {
  const diffHash = await hashFor(root, params.path);
  if (diffHash === createHash("sha256").update("").digest("hex")) {
    throw new RpcFault(ErrorCodes.invalidParams, `${params.path} has no diff to annotate`);
  }
  const row: AnnotationRow = { id: uuidv7(), line: params.line, note: params.note.trim(), createdAt: Date.now(), stale: false };
  db.prepare("INSERT INTO annotations (id, workspace_id, path, line, note, diff_hash, created_at) VALUES (?,?,?,?,?,?,?)").run(
    row.id, params.workspaceId, params.path, row.line, row.note, diffHash, row.createdAt,
  );
  return row;
}

export function deleteAnnotation(db: Database.Database, id: string): void {
  db.prepare("DELETE FROM annotations WHERE id = ?").run(id);
}
```

```tsx
// apps/desktop/src/renderer/DiffView.tsx
import { useCallback, useEffect, useState } from "react";
import type { RequestFn } from "./api.js";

export interface DiffLine {
  kind: "meta" | "hunk" | "add" | "del" | "context";
  text: string;
  oldLine?: number;
  newLine?: number;
}

interface Annotation {
  id: string;
  line: number;
  note: string;
  createdAt: number;
  stale: boolean;
}

export function parseDiff(text: string): DiffLine[] {
  const lines = text.split("\n");
  if (lines.at(-1) === "") lines.pop();
  const parsed: DiffLine[] = [];
  let oldLine = 0;
  let newLine = 0;
  for (const line of lines) {
    const hunk = /^@@ -(\d+)(?:,\d+)? \+(\d+)(?:,\d+)? @@/.exec(line);
    if (hunk !== null) {
      oldLine = Number(hunk[1]);
      newLine = Number(hunk[2]);
      parsed.push({ kind: "hunk", text: line });
      continue;
    }
    if (line.startsWith("--- ") || line.startsWith("+++ ") || line.startsWith("diff ") || line.startsWith("index ")) {
      parsed.push({ kind: "meta", text: line });
      continue;
    }
    if (line.startsWith("+")) {
      parsed.push({ kind: "add", text: line, newLine });
      newLine += 1;
      continue;
    }
    if (line.startsWith("-")) {
      parsed.push({ kind: "del", text: line, oldLine });
      oldLine += 1;
      continue;
    }
    parsed.push({ kind: "context", text: line, oldLine, newLine });
    oldLine += 1;
    newLine += 1;
  }
  return parsed;
}

export interface DiffViewProps {
  request: RequestFn;
  workspaceId: string;
  path: string;
}

export function DiffView({ request, workspaceId, path }: DiffViewProps) {
  const [lines, setLines] = useState<DiffLine[]>([]);
  const [annotations, setAnnotations] = useState<Annotation[]>([]);
  const [draft, setDraft] = useState<{ line: number; note: string } | undefined>(undefined);
  const [error, setError] = useState<string | undefined>(undefined);

  const refresh = useCallback(async (): Promise<void> => {
    try {
      const [diff, notes] = await Promise.all([
        request<{ diff: string }>("git.diff", { workspaceId, path }),
        request<{ diffHash: string; annotations: Annotation[] }>("annotation.list", { workspaceId, path }),
      ]);
      setLines(parseDiff(diff.diff));
      setAnnotations(notes.annotations);
      setError(undefined);
    } catch (cause) {
      setError(cause instanceof Error ? cause.message : "Could not load the diff");
    }
  }, [request, workspaceId, path]);

  useEffect(() => {
    void refresh();
  }, [refresh]);

  const addNote = async (line: number, note: string): Promise<void> => {
    if (note.trim() === "") return;
    try {
      const added = await request<Annotation>("annotation.add", { workspaceId, path, line, note: note.trim() });
      setAnnotations((current) => [...current, added]);
      setDraft(undefined);
    } catch (cause) {
      setError(cause instanceof Error ? cause.message : "Could not save the note");
    }
  };

  const removeNote = async (id: string): Promise<void> => {
    try {
      await request<{ ok: true }>("annotation.delete", { id });
      setAnnotations((current) => current.filter((annotation) => annotation.id !== id));
    } catch (cause) {
      setError(cause instanceof Error ? cause.message : "Could not delete the note");
    }
  };

  const current = annotations.filter((annotation) => !annotation.stale);
  const stale = annotations.filter((annotation) => annotation.stale);

  return (
```

```tsx
// apps/desktop/src/renderer/QuickOpen.tsx
import { useEffect, useMemo, useState } from "react";
import type { RequestFn } from "./api.js";

export interface QuickOpenProps {
  request: RequestFn;
  workspaceId: string;
  onPick: (path: string) => void;
  onClose: () => void;
}

/** `smt` matches `src/main.ts`: every query character appears in order. */
export function subsequence(path: string, query: string): boolean {
  const needle = query.toLowerCase();
  const haystack = path.toLowerCase();
  let index = 0;
  for (const char of haystack) {
    if (char === needle[index]) index += 1;
    if (index === needle.length) return true;
  }
  return needle.length === 0;
}

export function QuickOpen({ request, workspaceId, onPick, onClose }: QuickOpenProps) {
  const [files, setFiles] = useState<string[]>([]);
  const [query, setQuery] = useState("");
  const [active, setActive] = useState(0);

  useEffect(() => {
    void request<{ files: string[] }>("fs.files", { workspaceId }).then(
      (result) => setFiles(result.files),
      () => setFiles([]),
    );
  }, [request, workspaceId]);

  const matches = useMemo(() => files.filter((path) => subsequence(path, query)).slice(0, 20), [files, query]);
  const selected = matches[Math.min(active, Math.max(matches.length - 1, 0))];

  return (
    <div className="quick-open" role="dialog" aria-label="Open file">
      <input
        role="combobox"
        aria-label="Open file"
        aria-expanded="true"
        aria-controls="quick-open-results"
        autoFocus
        value={query}
        placeholder="Open a file…"
        onChange={(event) => {
          setQuery(event.target.value);
          setActive(0);
        }}
        onKeyDown={(event) => {
          if (event.key === "Escape") {
            event.preventDefault();
            onClose();
          }
          if (event.key === "ArrowDown") {
            event.preventDefault();
            setActive((current) => Math.min(current + 1, matches.length - 1));
          }
          if (event.key === "ArrowUp") {
            event.preventDefault();
            setActive((current) => Math.max(current - 1, 0));
          }
          if (event.key === "Enter" && selected !== undefined) {
            event.preventDefault();
            onPick(selected);
          }
        }}
      />
      <ul id="quick-open-results" role="listbox" aria-label="Matching files">
        {matches.map((path, index) => (
          <li key={path} role="option" aria-selected={path === selected} onClick={() => onPick(path)}>
            {path}
          </li>
        ))}
      </ul>
    </div>
  );
}
```

```tsx
import type { Tab } from "./tabs.js";

export interface TabsProps {
  tabs: readonly Tab[];
  activeId: string | undefined;
  onSelect: (tabId: string) => void;
  onClose: (tabId: string) => void;
  /** Session titles by session id; a missing entry renders `Untitled chat`. */

  dirty?: ((path: string) => boolean) | undefined;
}

function labelFor(tab: Tab, titles: Readonly<Record<string, string>>, dirty?: (path: string) => boolean): string {
  if (tab.kind === "chat") {
    const title = titles[tab.sessionId] ?? "";
    return title === "" ? "Untitled chat" : title;
  }
  const name = tab.path.split("/").at(-1) ?? tab.path;
  const text = tab.kind === "diff" ? `diff: ${name}` : name;
  return tab.kind === "editor" && dirty?.(tab.path) === true ? `${text} •` : text;
}
```

- [ ] **Step 1: Document the editor**

Add an `## Editing` section after `## The chat shell`:

- **Layout.** `Chat list` / `File list` switch the list pane; editor and diff tabs sit beside chat
  tabs, and `⌘W` closes whichever tab is active.
- **Saving.** `⌘S` writes through `fs.write`; the write carries the `mtimeMs` the file had when it was
  read, so a file changed by the agent or another program reports a conflict and keeps the draft.
- **Diff stats.** The inspector and the chat header read `git.status` (adds/deletes against `HEAD`),
  refreshed after each save and shortly after a `file.changed` event. A non-git workspace shows no
  stats and still edits and saves.
- **Diffs and notes.** `Show diff` opens a unified diff tab; clicking a line number stores a note
  against that diff. When the file changes, old notes move to `Notes from an earlier version`
  instead of pointing at unrelated lines.
- **Limits.** Listing is capped at 2 000 entries, reads at 2 MiB (marked truncated), writes at
  5 000 000 characters, and quick open at 5 000 files. Non-UTF-8 content and symlinks are refused or
  skipped rather than rendered.

## Risks

- **Monaco bundle size.** The editor adds several megabytes to the renderer chunk. It is lazily
  imported, so chat startup is unaffected; packaging must ship `dist/renderer` as a whole.
- **Worker loading under Electron.** `?worker` relies on Vite's emitted asset URLs with `base: "./"`;
  if the worker fails, Monaco falls back to the main thread and the editor still works, just slower.
- **git availability.** `git` is a hard dependency for stats and diffs; without it the workspace is
  editable but the inspector reports nothing. `NOIR_GIT_COMMAND` exists for non-PATH installs.
- **Large repositories.** `git.status` runs two git processes per refresh; the event debounce keeps
  that to one per 250 ms burst. A very large repo may still be slow, and the 5 s timeout turns that
  into a silent empty status rather than a hang.
- **Concurrent writers.** `expectedMtimeMs` catches most races but not same-millisecond writes; the
  next read reconciles the buffer.
- **Annotation identity.** Notes key on the diff hash; a reformat that changes every line marks all
  notes stale instead of mis-attaching them — deliberate, and recoverable by re-adding.
